## [0.1.0] — 2026-10-27

Первая версия настольной главной книги для бухгалтера в Азербайджане.

### Добавлено
- Ядро: документ из проводок Дт/Кт с субконто (до трёх на сторону), деньги — целые
  копейки; черновик → проведение, правка на месте в открытом периоде, сторно в закрытом,
  журнал действий с причиной; закрытие периода.
- Несколько компаний — файл `*.gl` на компанию; параллельные книги: общая, МСФО, налог.
- План счетов по шаблонам («classic», «1c77»), классы и типы счетов, роли и счета по
  умолчанию; справочники с группами, тегами, VÖEN, договорами.
- Валюты: курсы ЦБА, учёт в валюте по счёту, переоценка, конвертация через 57.
- Ввод с клавиатуры как в 1С, быстрая строка Ctrl+L, шаблоны операций, вставка из Excel,
  импорт документов, начальные остатки.
- Отчёты: ОСВ (развёрнутая по субконто), ОСВ по субконто, карточка и анализ счёта и
  субконто, баланс, ОПиУ по IFRS 18, движение денег, колонки по месяцам и кварталам,
  «Все отчёты», выгрузка в Excel, журнал для hledger, «Передача дел».
- Модули: склад (себестоимость, пересчёт, доп. расходы), покупки и продажи, e-qaimə и
  ƏDV DH с портала e-taxes со сверкой, банк (выписки, авансы, комиссии, файлы банков),
  ƏDV (зачёт, реестр, сверка оплат), перестроение проводок модулей с даты.
- Надёжность: резервные копии, проверка целостности, режим «только просмотр», миграции
  «всё или ничего»; AI-помощник по MCP; API и `modern-gl-cli` для разработчиков.
- Интерфейс азербайджанский и русский, язык документов — настройка компании; темы.
