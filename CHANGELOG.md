# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Подробности каждого пункта — в решениях `docs/DECISIONS.md` (`| D<номер> |`).

## [Unreleased]

## [0.1.6] — 2026-11-03

### Изменено
- Новая версия ищется при каждом запуске и затем раз в час, а не раз в день: исправление
  доходит до коллеги сразу. Строка «Вышла версия …» — красная кнопка, чтобы заметить.

### Исправлено
- Установка обновления не запускалась («Windows cannot find '\'»): команда для cmd
  передавалась списком, и кавычки в ней экранировались. Теперь одной строкой.

## [0.1.5] — 2026-11-03

Без изменений в программе: выпуск для живой проверки обновления из программы (D191) —
установленная 0.1.4 должна показать «Вышла версия 0.1.5 — обновить» и поставить её сама.

## [0.1.4] — 2026-11-03

### Добавлено
- Обновление из программы: раз в день программа спрашивает GitHub о новой версии и
  показывает внизу боковой панели «Вышла версия … — обновить»; по щелчку скачивает
  установщик и ставит его сама, программа закрывается и открывается обновлённой. Файлы
  компаний не трогаются.

## [0.1.3] — 2026-11-03

### Исправлено
- Окно входа на портал не открывалось: кнопка «Обновить страницу» обращалась к браузеру
  до его создания (с D115). Браузер создаётся первым; тест с подменным движком.
- Qt 6: общий контекст OpenGL для встроенного браузера включается до создания программы.

## [0.1.2] — 2026-11-03

### Исправлено
- Установщик 0.1.1 не содержал встроенного браузера (QtWebEngine): «Загрузить с портала»
  в покупках, продажах и ƏDV DH падало с ошибкой. Браузер снова в сборке; в сборке без
  него программа теперь говорит об этом словами, а не падает.

## [0.1.1] — 2026-11-03

### Добавлено
- ОСВ по месту (D190): строку счёта можно развернуть прямо в отчёте — по субконто,
  корреспондирующим счетам или месяцам (→, Shift+→, Ctrl+→, Ctrl+← и правый щелчок);
  сортировка по колонке, вид «одна колонка», суммы в тысячах; сохранённые виды отчёта
  («⋯ → Сохранить вид…»), хранятся в файле компании.

### Изменено
- Субсчёт стоит ближе к счёту: отступ уровня — три пробела во всех отчётах.
- Все колонки сумм одной ширины — по самой широкой (пустой «Кт» был узкой щелью).
- Корреспондирующий счёт по-азербайджански — «qarşılıqlı hesab».
- Репозиторий открыт: сборка установщика — в GitHub Actions, Release доступен по ссылке.

### Исправлено
- ОСВ: «Развернуть ▸» из правого щелчка открывал строку не тем видом.

## [0.1.0] — 2026-10-29

Первая версия настольной главной книги для бухгалтера в Азербайджане.

### Добавлено
- Установщик для Windows `modern-gl-<версия>-setup.exe` (без прав администратора; новая
  версия ставится поверх прежней, файлы компаний не трогаются) и zip без установки; версия
  программы внизу боковой панели, в журнале и в окне «Ошибка»; иконка программы.
- Инструменты разработки: CI на ubuntu и windows, покрытие (`pytest-cov`), свойства
  (`hypothesis`), снимки отчётов (`syrupy`), `pre-commit`, выпуск одной командой
  (`scripts/release.py`), `requirements.txt` из `uv.lock`.

### Добавлено
- Ядро: документ из проводок Дт/Кт с субконто (до трёх на сторону), деньги — целые
  копейки; черновик → проведение, правка на месте в открытом периоде, сторно в закрытом,
  журнал действий с причиной; закрытие периода.
- Несколько компаний — файл `*.gl` на компанию; параллельные книги: общая, МСФО, налог.
- План счетов по шаблонам («classic», «1c77»), классы и типы счетов, роли и счета по
  умолчанию; справочники с группами, тегами, VÖEN, договорами.
- Валюты: курсы ЦБА, учёт в валюте по счёту, переоценка, конвертация через 57.
- Ввод с клавиатуры как в 1С, быстрая строка Ctrl+L, шаблоны операций, вставка из Excel,
  импорт документов, начальные остатки.
- Отчёты: ОСВ (развёрнутая по субконто), ОСВ по субконто, карточка и анализ счёта и
  субконто, баланс, ОПиУ по IFRS 18, движение денег, колонки по месяцам и кварталам,
  «Все отчёты», выгрузка в Excel, журнал для hledger, «Передача дел».
- Модули: склад (себестоимость, пересчёт, доп. расходы), покупки и продажи, e-qaimə и
  ƏDV DH с портала e-taxes со сверкой, банк (выписки, авансы, комиссии, файлы банков),
  ƏDV (зачёт, реестр, сверка оплат), перестроение проводок модулей с даты.
- Надёжность: резервные копии, проверка целостности, режим «только просмотр», миграции
  «всё или ничего»; AI-помощник по MCP; API и `modern-gl-cli` для разработчиков.
- Интерфейс азербайджанский и русский, язык документов — настройка компании; темы.
