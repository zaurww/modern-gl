# Modern GL

English: `README.en.md` — a short entry for an outside developer.

Настольная главная книга для бухгалтера в Азербайджане: проводки Дт/Кт с субконто как в
1С 7.7, несколько компаний (файл на компанию), параллельные книги (общая / МСФО / налог).
Модули поверх ядра: банк, склад, покупки и продажи, конвертация валют, e-qaimə и ƏDV DH с
портала e-taxes, AI-помощник (MCP). Интерфейс — азербайджанский и русский.

Python ≥ 3.12, PySide6, SQLite. Один файл `*.gl` — одна компания.

## Запуск и проверки

```sh
uv sync                      # зависимости (uv.lock), Python 3.12 (.python-version)
uv run modern-gl             # компании — *.gl в «Документы/Modern GL» (--data <папка>); --demo, --demo-year
uv run pytest -q -n auto     # все тесты, параллельно; --cov — покрытие ([tool.coverage] в pyproject)
uv run ruff check . && uv run ruff format --check .
uv run pyright               # 0 ошибок
uv run --with pre-commit pre-commit install   # те же проверки перед коммитом (.pre-commit-config.yaml)
uv export --no-dev --format requirements-txt --no-hashes -o requirements.txt   # после uv add / uv lock
```

В Linux без экрана: `QT_QPA_PLATFORM=offscreen` и библиотеки `libegl1 libgl1 libxkbcommon0
libfontconfig1 libdbus-1-3` (как в `.github/workflows/ci.yml`; там же `hledger`). Скриншоты —
`uv run python scripts/screenshots.py <папка>`. Выпуск — `uv run python scripts/release.py
<версия> --push`: тег `v*` собирает установщик и zip для Windows (`.github/workflows/release.yml`,
`packaging/`) в GitHub Release; что изменилось — `CHANGELOG.md`.

## Как устроено

Слои, сверху вниз. Слой импортирует только себя и слои ниже — это проверяет тест
(`tests/test_architecture.py::test_layers_depend_downwards_only`).

| Слой | Пакет `src/modern_gl/…` | За что отвечает | Чего там нет |
|---|---|---|---|
| Интерфейс | `desktop` | страницы, формы, таблицы (PySide6) | SQL, правил учёта, транзакций |
| Помощник | `assistant` | MCP-сервер для AI: те же отчёты и сценарии | своей логики учёта |
| API | `api` | для разработчиков: `modern_gl.api`, `modern-gl-cli` (`docs/API.md`) | своей логики учёта |
| Отчёты | `reporting` | ОСВ, карточка, баланс, ОПиУ, ДДС, склад, e-qaimə — только чтение, агрегация в SQL | записи |
| Сценарии | `application` | `Ledger` и модули (запись, одна транзакция на сценарий), общее чтение (`queries`, `catalog`, `books`), точки подключения модулей, файлы компаний | Qt |
| Движок | `infrastructure` | `sqlite3` только здесь: соединение, миграции, файл компании, копии, CSV/Excel, порталы | правил учёта |
| Предметная область | `domain` | деньги (целые копейки), даты, периоды, формулы | SQL, Qt |
| Тексты | `i18n`, `i18n_az` | `tr()` и переводы | — |

Ключевые правила, каждое с тестом:

- **Ядро не знает о модулях.** Ядро — главная книга, план счетов, справочники. Модуль
  (банк, склад, конвертация, e-qaimə) — свой пакет в `application/`, свои таблицы своей
  миграцией, свои страницы в `desktop/`; с ядром связан только проводками и несколькими
  точками подключения (`docs/ARCHITECTURE.md`, раздел 3).
- **Деньги — целые копейки**, никаких `float`. Проведённое не исправляется без следа.
- **Схема — только миграциями** `infrastructure/migrations/NNNN_*.sql`; написанная не
  меняется (хэши в тесте). Каждая таблица — `company_id NOT NULL`, составные внешние
  ключи `(company_id, id)`, индекс на каждую ссылку.
- **Размер:** модуль ≤ 600 строк, класс ≤ 500, функция ≤ 80, сложность ≤ 12.
- **Окно не открывает транзакцию** и не пишет SQL: сценарий — один метод `Ledger`/`Inventory`.

## Что читать и в каком порядке

1. `docs/CONCEPT.md` — рамка: зачем программа, учётная модель, данные. Меняется только
   решением владельца.
2. `docs/ARCHITECTURE.md` — как устроено: слои, ядро и модули, данные, интерфейс, проверки.
   Вид страниц и отчётов — `docs/DESIGN.md`.
3. `docs/ENGINEERING.md` — инженерные правила и чек-лист новой функции; раздел «Долг» —
   известные отступления и план.
4. `docs/decisions/` — решения `D1…D152`, файл на решение (статус, контекст, решение,
   последствия), индекс `README.md` там же; только добавление. На номера ссылаются код и
   документы; при расхождении решение важнее остальных документов.
5. `docs/STATUS.md` — что есть и что дальше; `docs/CODE_QUALITY.md` — размер и обзоры кода;
   документы модулей — `INVENTORY.md`, `REPORTING.md`, `BOOKS.md`, `EQAIME_RECONCILIATION.md`,
   `ASSISTANT.md`; `docs/history/` — летопись сессий.

`CLAUDE.md` в корне — сжатая рабочая карта (структура пакетов и правила) для AI-помощника
и разработчика; читается в начале каждой сессии.

## Словарь

Слова, которые встречаются в коде, документах и интерфейсе без перевода:

| Слово | Что это |
|---|---|
| проводка Дт/Кт, субконто | запись «дебет счёта / кредит счёта + сумма»; субконто — аналитика счёта (контрагент, договор…), до трёх на счёт |
| книга, слой | документ лежит в одном слое (общий, МСФО, налог); книга — набор слоёв (D7) |
| e-qaimə | электронная накладная с портала налоговой (e-taxes); её номер связывает покупку, ƏDV и оплату |
| ƏDV, ƏDV DH | НДС; ƏDV depozit hesabı — депозитный счёт НДС на портале |
| VÖEN | ИНН компании или контрагента |
| «Bu gün», «Diqqət tələb edir», «Geri al» | экраны и кнопки: «Сегодня», «Требует внимания», «Отменить» |
| D<номер> | решение в `docs/decisions/` (`D072-…`) |

## Языки

- Код — имена, докстринги, комментарии — английский. Азербайджанские названия экранов в
  них — как в интерфейсе (см. словарь).
- Документы, решения, сообщения коммитов — русский.
- Тексты интерфейса — только через `tr("русский текст")`, перевод — `i18n_az/` (файл на функцию);
  интерфейс по умолчанию азербайджанский.

## Что охраняют тесты

| Что | Тест |
|---|---|
| Слои только вниз; ядро не читает таблиц и кода модулей; нет SQL в виджетах; движок только в `infrastructure`; окно не открывает транзакцию | `tests/test_architecture.py` |
| Схема: `company_id`, составные ключи, индексы, типы, неизменные миграции | `tests/test_database.py` |
| Размер кода 600 / 500 / 80 | `tests/test_code_size.py` |
| Документы остаются короткими; решения — в одном формате, индекс актуален | `tests/test_docs_size.py`, `tests/test_decisions.py` |
| Переводы на каждый текст | `tests/test_i18n.py` |
| Режим «только просмотр» ничего не пишет | `tests/test_read_only_ui.py` |
| Перестроение проводок модулей ничего не меняет | `tests/test_rebuild.py` |
| Учёт — цифры посчитаны вручную | `tests/conftest.py`, `tests/test_demo_year.py` |

## Новый модуль или функция

Пройти чек-лист в `docs/ENGINEERING.md`: свой пакет и таблицы, точки подключения
(`document_owners`, `rebuild_postings`, `attention_source`, команды Ctrl+K, роли счетов,
место в боковой панели), тест с ручными цифрами, зелёные `ruff`, `pyright`, `pytest`.
Решение — файлом в `docs/decisions/` (`D-new-<slug>.md` в ветке).
