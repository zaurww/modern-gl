# AI-помощник: книги для AI через MCP (D83)

Программа отдаёт книги AI как инструменты по протоколу MCP (Model Context Protocol).
Подключается к Claude Desktop или любому MCP-клиенту. **Только чтение:** каждая компания
открывается снимком (D80), поэтому AI ничего не может изменить, а файл, открытый в
программе, не блокируется.

## Подключение к Claude Desktop

1. Один раз: `uv sync` в папке программы (появится `.venv\Scripts\modern-gl-mcp.exe`).
2. Claude Desktop → Settings → Developer → Edit Config (файл
   `%APPDATA%\Claude\claude_desktop_config.json`), добавить:

```json
{
  "mcpServers": {
    "modern-gl": {
      "command": "D:\GL AZE\.venv\Scripts\modern-gl-mcp.exe"
    }
  }
}
```

3. Перезапустить Claude Desktop. В чате спросить, например:
   «Какие e-qaimə Zaur не оплачены на конец октября?»,
   «Проверь ОСВ Sabir за сентябрь: есть ли сальдо не на своей стороне и откуда оно?»,
   «Покажи карточку 60 по SOCAR за квартал».

Компании — те же, что в программе: её папка и запомненные файлы (из настроек программы).
Аргументы (в `"args": [...]`): `--data <папка>` — другая папка, `--file <X.gl>` — ещё файл,
`--lang ru|az` — язык сообщений (по умолчанию — язык программы).

## Инструменты

| Инструмент | Что отвечает |
|---|---|
| `companies` | список компаний |
| `chart_of_accounts` | план счетов: код, название, класс, тип, субконто; список справочников |
| `trial_balance` | ОСВ за период (книга `common` / `ifrs` / `tax`), флаг «сальдо не на своей стороне» |
| `account_card` | карточка счёта: проводки, корр. счёт, нарастающее сальдо |
| `account_analysis` | обороты счёта по корр. счетам |
| `subconto_balance` | ОСВ счёта по субконто (60 по контрагентам) |
| `documents` | журнал за период, поиск по содержанию и номеру, только черновики |
| `document` | документ по номеру со всеми проводками |
| `directory` | элементы справочника (VÖEN, группы, метки), поиск |
| `e_qaime` | e-qaimə: контрагент, обороты, ƏDV, неоплаченный остаток |

Суммы — строки в манатах с двумя знаками («1234.50»). Длинный список обрезается на 500
строках, `left_out` — сколько не показано.

## Проверка без Claude

```
uv run modern-gl-mcp < запросы.jsonl
```
Одна строка — один запрос JSON-RPC (`initialize`, `tools/list`, `tools/call`).
