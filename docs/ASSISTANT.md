# AI-помощник: книги для AI через MCP (D83, D84)

Программа отдаёт книги AI как инструменты по протоколу MCP (Model Context Protocol).
Подключается к Claude Desktop или любому MCP-клиенту. **По умолчанию только чтение:** каждая
компания открывается снимком (D80), поэтому AI ничего не может изменить, а файл, открытый в
программе, не блокируется. Запись — только флагами: черновики и правки (ниже).

## Подключение из программы

Меню компании (название вверху слева) → **«AI-помощник…»** (или Ctrl+K → «AI-помощник»):
выбрать, что разрешено (только чтение · черновики · правки), отметить программу (Claude
Desktop, Claude Code — что установлено) → «Применить» → перезапустить AI-программу (Claude
Desktop — полностью: значок у часов → Quit). Снятая галочка отключает. Программа меняет в
настройках AI только свою запись `modern-gl`.

## Подключение вручную (Claude Desktop)

1. Сервер — `modern-gl-mcp.exe` в папке программы (из исходников: `uv sync`, он в
   `.venv\Scripts`).
2. Claude Desktop → Settings → Developer → Edit Config (файл
   `%APPDATA%\Claude\claude_desktop_config.json`; у сборки из Microsoft Store —
   `%LOCALAPPDATA%\Packages\Claude_…\LocalCache\Roaming\Claude\`), добавить:

```json
{
  "mcpServers": {
    "modern-gl": {
      "command": "D:\\GL AZE\\.venv\\Scripts\\modern-gl-mcp.exe"
    }
  }
}
```

3. Перезапустить Claude Desktop. В чате спросить, например:
   «Какие e-qaimə Zaur не оплачены на конец октября?»,
   «Проверь ОСВ Sabir за сентябрь: есть ли сальдо не на своей стороне и откуда оно?»,
   «Покажи карточку 60 по SOCAR за квартал».

Компании — те же, что в программе: её папка и запомненные файлы (из настроек программы).
Аргументы (в `"args": [...]`): `--data <папка>` — другая папка, `--file <X.gl>` — ещё файл,
`--lang ru|az` — язык сообщений (по умолчанию — язык программы).

## Инструменты

| Инструмент | Что отвечает |
|---|---|
| `companies` | список компаний |
| `chart_of_accounts` | план счетов: код, название, класс, тип, субконто; список справочников |
| `trial_balance` | ОСВ за период (книга `common` / `ifrs` / `tax`), флаг «сальдо не на своей стороне» |
| `account_card` | карточка счёта: проводки, корр. счёт, нарастающее сальдо |
| `account_analysis` | обороты счёта по корр. счетам |
| `subconto_balance` | ОСВ счёта по субконто (60 по контрагентам) |
| `documents` | журнал за период, поиск по содержанию и номеру, только черновики |
| `document` | документ по номеру со всеми проводками |
| `directory` | элементы справочника (VÖEN, группы, метки), поиск |
| `e_qaime` | e-qaimə: контрагент, обороты, ƏDV, неоплаченный остаток |

Суммы — строки в манатах с двумя знаками («1234.50»). Длинный список обрезается на 500
строках, `left_out` — сколько не показано.

## Черновики от AI (D84)

С флагом `--allow-drafts` AI может готовить **черновики** документов журнала:

```json
"modern-gl": {
  "command": "D:\\GL AZE\\.venv\\Scripts\\modern-gl-mcp.exe",
  "args": ["--allow-drafts"]
}
```

| Инструмент | Что делает |
|---|---|
| `create_draft` | черновик: дата, содержание, проводки (счёт кодом, субконто — имя или VÖEN, сумма строкой) |
| `update_draft` | заменить свой черновик целиком |
| `delete_draft` | удалить свой черновик |

- Проводит только человек — в программе, как обычно. AI не меняет чужие документы и
  проведённые.
- Автор черновика — «AI · Claude» (шапка документа, колонка «Автор» в журнале).
- Контрагента, банка, договора нет в справочнике — AI скажет, что его надо добавить.
- В ответе AI видит, провёлся бы черновик, и если нет — почему; исправляет сам.
- Программу можно не закрывать: черновик появится в журнале при следующем его открытии.

Пример: «Заведи черновик оплаты SOCAR по e-qaimə MT260111994450 с Pashabank 5 февраля».

## Правки от AI (D234)

С флагом `--allow-edits` (включает и черновики) AI исправляет ошибки, на которые вы указали:

| Инструмент | Что делает |
|---|---|
| `change_document` | заменить документ журнала целиком; проведённый остаётся проведённым, номер тот же |
| `set_e_qaime` | сменить только номер e-qaimə в строках — документ журнала или операция банка |
| `unpost_document` | отменить проведение (дубликат) — документ журнала или операция банка |

- Только открытый период; один документ за вызов; клиент спрашивает разрешение на каждый.
- AI **не удаляет** и **не проводит черновики**: дубликат становится черновиком, удаляете вы.
- Причина обязательна; прежнее содержимое и причина — в «Истории изменений» документа и в
  журнале действий, автор — «AI · Claude».
- Перед первой правкой за запуск — копия файла «до правок AI» (окно «Резервные копии»).
- Документы склада, конвертации, подотчёта AI не правит — скажет, что это делаете вы.

Пример: «Оплата №812 разнесена на e-qaimə MT2611…450, а должна на MT2611…448 — исправь»;
«Документы №640 и №655 — один и тот же платёж, отмени проведение второго».

## Проверка без Claude

```
uv run modern-gl-mcp < запросы.jsonl
```
Одна строка — один запрос JSON-RPC (`initialize`, `tools/list`, `tools/call`).
