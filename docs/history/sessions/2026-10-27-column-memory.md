# 2026-10-27 — claude/column-memory (D177)

Пользователь: «3» — STATUS «Дальше», п. 3: запоминать ширину колонок, сдвинутую мышью, и
порядок колонок.

- Подпись колонки отчёта тянется мышью — колонка переезжает, пара Дт/Кт целиком, первая
  остаётся первой. Порядок держит модель (`ReportModel.arrange`), шапка сразу
  возвращается к своему: подписи пар рисуются по модели, как прежде.
- Ширина, сдвинутая мышью (`GroupHeader.held` — мышь нажата), сохраняется при отпускании;
  узкое окно её не отнимает (`ReportTable.fixed`).
- Всё — на вид отчёта, рядом с выбором колонок D116; «Колонки по умолчанию» сбрасывает и
  порядок, и ширины. Таблица спрашивает выбор у страницы каждый раз: ключ страницы
  задаётся после таблицы (первый вариант запоминал под общим «report»).
