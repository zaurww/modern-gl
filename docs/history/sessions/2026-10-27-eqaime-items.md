# 2026-10-27 — claude/eqaime-items (D156: «Товар» или «Услуга» в строке покупки)

Пользователь открыл черновик покупки из e-qaimə: четыре строки — товары, а программа
взяла их услугами (товаров с такими названиями ещё не было), счёт склада в «Xərc hesabı»
не выбирается (так задумано: товар — через склад). Сделать строку товаром из черновика
было нельзя: «+ Добавить «…»» в имени строки-услуги молча менял текст.

- Решение: вид строки — только «Товар» / «Услуга»; назначение (для продажи, для себя,
  малоценка) — счёт запасов товара.
- `Inventory.add_named_items` (`application/inventory/catalog.py`) — товары по именам в
  одной транзакции, без дублей.
- Колонка «Вид» (`KIND`) в покупке, видна при строке-услуге; `goods_lines.py` — окно
  «Строки — товары»; `unit_box` вынесен из `ItemDialog` (`inventory_page/dialogs.py`).
- В Excel «Вид» не копируется и не вставляется по порядку колонок.
- Попутно: на C: кончилось место — очищен npm-кэш (9,8 ГБ) с согласия пользователя.

Тесты: `tests/test_goods_lines.py` (цифры вручную в докстрингах).
