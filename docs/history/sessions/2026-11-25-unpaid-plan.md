# 2026-11-25 — «Bu gün» на только что загруженном годе

Пользователь открыл демо-сеть ресторанов (13 800 документов, 107 500 проводок, файл создан
программно и ни разу не закрывался программой) — ОСВ показала «Məlumat yoxdur».

- Причина: фоновое чтение «Bu gün» считало деньги без номера (D206) запросом, который соединял
  документы с проводками счетов расчётов: без статистики планировщик читал все проводки счёта
  на каждый документ — 105 с. ОСВ ждала в той же очереди и до конца чтения показывала пустое.
- Запрос переписан: проводки по счёту, документ — проверкой `IN (SELECT id FROM docs)`; на том же
  файле 0,03 с, весь источник «неоплаченные e-qaimə» — 0,5 с. Со статистикой (после первого
  закрытия файла) и старый запрос занимал 0,08 с.
- Тест — план запроса без статистики (`test_database.py`); на прежнем запросе падает.

Замечено, не исправлено: страница, ждущая фонового чтения, показывает «нет данных», а не
«читается»; статистика собирается только при закрытии файла — после большой загрузки в той же
сессии её нет (остальные чтения «Bu gün» и отчёты на таком файле — до 1 с, замерено).
