# 2026-11-04 — `claude/import-account-fallback`: счёт новой услуги при загрузке e-qaimə

Пользователь: повторяющиеся услуги (аренда, бухгалтерия) — предлагать счёт, который был.
Форма покупки это уже делала (D76), окно загрузки — нет. Сделано (D196): новая услуга
поставщика получает счёт той же услуги у другого поставщика, иначе последний расход
поставщика, с подписью «— проверьте»; подтверждение — черновик. Полный прогон: в первом
запуске под нагрузкой упали два несвязанных теста, повтор — зелёный.
