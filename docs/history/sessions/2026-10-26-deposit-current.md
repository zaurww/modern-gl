# 2026-10-26 — ветка `claude/deposit-current`

- **ƏDV DH: ƏDV поставщику с расчётного счёта — не операция депозита.** Портал показывает
  в операциях депозита и ƏDV, заплаченный с расчётного счёта на депозит поставщика
  («Hesabın növü: Cari hesabı», «nb»); остаток депозита его не считает. Загрузка вычитала
  его — у пользователя остаток ушёл в минус ровно на эту сумму (3 490.21; портал 493.87).
  Теперь `deposit_import.paid_from_bank` пропускает такой расход (приход «Cari hesabı» —
  покупатель платит со своего банка — остаётся). Тест — по файлу портала пользователя.
- **Выписки счёта банка:** в таблице — дата без дня недели (в заголовке выписки остался),
  порядок — от старой к новой.
- Не проверено на живом портале: имя поля (`account` = `CURRENT` / `operationType`
  `CURRENT_…`); запасной признак — номер документа не из цифр («nb»).
