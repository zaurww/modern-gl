# 2026-11-06, ветка paste-column

Пользователь вносил 70 товаров декларации в «Покупку» столбцами из Excel: «он вставляет
miqdar новыми строками. Имена остаются внизу, появляются новые 70 строк».

Сделано (`inventory_document_page/lines_clipboard.py`):
- несколько строк без колонки товара (количество, цена, сумма) идут в те же строки, как в
  Excel; за последней строкой — новые;
- пустая ячейка столбца оставляет свою строку: числа ниже не съезжают на чужой товар;
- заголовок над одним столбцом («Miqdar») — заголовок, а не значение первой строки;
- имена на строки без товара (сначала количества, потом имена) встают в эти строки; имена на
  строку со своим товаром — по-прежнему новыми строками, ничего не затирается.

Проверено: 7 новых тестов в `tests/test_inventory.py`, весь набор, pyright, ruff.

Открыто, ждёт решения пользователя: товары из вставки создаются сразу и остаются после
удаления строк (пустые в «Anbar», удаление по одному); вставленный обрывок имени молча
находит похожий товар (`resolve_choice`); в таблице проводок та же вставка новыми строками.
