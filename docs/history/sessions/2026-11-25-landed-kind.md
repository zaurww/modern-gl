# 2026-11-25 — «Куда → Əlavə xərc» в покупке

Пользователь спросил, как склад связан с доп. расходами (декларация, фактура брокера, оплата
таможне с банка), и заметил: счёт 15 знают не все. Сравнили с SAP (транзитный счёт спрятан за
видом расхода) и решили сделать так же в два шага.

Шаг 1 сделан (D219):
- строка покупки, «Куда»: «Склад» / «Счёт» / «Əlavə xərc (malın maya dəyəri)» — счёт ожидания
  ставится сам; вид строки выводится из её счёта, ничего нового не хранится;
- «Провести черновики» предлагает этот выбор первым; окно загрузки e-qaimə называет его словом;
- перенос без изменения логики: «Куда» — в `lines_kind.py`, поиск и создание счёта ожидания —
  из банка в `default_accounts.landed_cost_account`.

Проверено тестами и скриншотом формы; вживую на Windows не смотрели.

Шаг 2 — не начат, ждёт, пока пользователь попробует первый. Что о нём известно:
- ссылка строки расхода на покупку товара; номер декларации в e-qaimə брокера — только подсказка;
- таможня: оплаты идут авансом (в том числе по qısa idxal bəyannaməsi с другим номером), счёт с
  разбивкой (ƏDV, акциз, сборы) приходит с товаром — начисление по декларации нужно отделить от
  оплаты; «Таможенный платёж…» (D212) делает их вместе и акциз отдельно не знает;
- проверить тестом: ƏDV, введённый строкой расхода партии, идёт на 19 без номера декларации
  (`_vat_postings(company_id, ("", ""), …)` в `landed_cost.py`) — зачёт его, похоже, не видит.
