# 2026-11-03, ветка excel-flat (D193 «Проводки для Excel»)

Пользователь: «сомнения, насколько программа будет удобна» → разбор по документам: правила
вида проверяются тестами, но живой приёмки не было, переводы AZ не проверены, ОСВ ~1330 px.
Дальше про Logo ERP: отчёты с фильтрами, «excel-friendly», SQL. Решено: SQL-контракт
(представления) — не сейчас, без реального случая; сводные в программе не строим — «Excel
должен быть плоским и удобным для получения pivot». Мои добавления принял: субконто
колонками по видам, лист «Стороны» (две строки на проводку, знак), остатки на начало
строками, год/месяц/квартал колонками, иерархия счёта, таблица Excel, строка проверки.
Сделано: `reporting/flat_postings.py` + `flat_excel.py`; `report_file.py` — даты и числа,
ListObject, несколько листов (`save_tables`); страница в каталоге и Ctrl+K; переводы
`i18n_az/flat_postings.py` (писал Claude — проверить). Тест: сводная по «Стороны» даёт
конечные сальдо февраля из `conftest.py`; папка и тег — свои колонки; окно сохраняет файл.
Правила: ядро не тронуто, модуль узнаётся через `document_owners`; SQL общий; «Уют» —
период капсулой, Enter/двойной щелчок ведёт к документу, одна синяя кнопка. Скриншоты
offscreen: страница и «Все отчёты» — по DESIGN. 1766 тестов, ruff, pyright 0.

сводная на таблице «Стороны» на Windows.
