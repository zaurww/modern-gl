# 2026-10-29, ветка claude/statement-columns (D-new «колонки по субконто»)

Пользователь: клиент-ресторан, 11 точек, учёт по Uniform System of Accounts for
Restaurants (шпаргалка и шаблоны на диске). Оценка: ядро справляется — точка это
субконто «Lokasiya», Head Office — его элемент, закупки сразу в COGS (книга, раздел 22).
Решено: «программа не только для ресторана» — делать универсальное, POS пока не трогать.

- ОПиУ «Колонки: По субконто ‹справочник›» — колонка на элемент по месту справочника на
  счёте, «Не указано», «Итого» тем же кодом; справочники — со счетов доходов и расходов.
- Строки «По счетам» под группами плана: группа — строкой с суммой, счета глубже;
  единственный узел уровня не повторяется (`Names.account_lines`, `Line.depth`) — баланс,
  ОПиУ, ДДС.
- «Процент от выручки» — «%» после каждой колонки сумм (`columns.share`).
- Двойной щелчок по ячейке элемента — карточка с фильтром, если справочник первый на счёте.
- Тест с ручными цифрами: два магазина и офис, COGS 410 / 150, операционные 350 / 280 / 70 / 10.

Обсуждено, не сделано: Prime Cost как сквозной подытог, распределение общих расходов
(проводка в конце месяца, шаблон D23), шаблон плана USAR, загрузчик файла POS.
