# 2026-10-27 — claude/document-language (D152)

Ошибка из сессии `schema-safety`: перестроение и пересчёт склада после смены языка
интерфейса переписывали тексты проводок модулей. Пользователь выбрал «1» — язык документов
как настройка компании.

- Места, где текст попадает в базу, найдены опытом: демо-год построен на az и на ru, все
  текстовые колонки сравнены — `postings.memo`, `documents.memo` (9 шаблонов) — и по коду
  (назначение платежа, элемент «Комиссия банка» по имени, «Без названия» e-qaimə, начальные
  остатки). Там `tr` → `trd`.
- `companies.document_language` (0054), `application/document_language.py` (`open_in`:
  старый файл — язык его текстов), `Ledger.set_document_language`, меню «Язык документов».
- `tests/test_document_language.py`; тест прежних версий теперь перестраивает файл с
  азербайджанскими текстами при русском интерфейсе без изменений. Фикстура `schema_0054`.

Проверено: `pytest -n auto` (1452), `ruff`, `pyright`.
