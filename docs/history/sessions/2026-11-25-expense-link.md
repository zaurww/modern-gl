# 2026-11-25 — расход партии → покупка товара

Шаг 2 после D219, первая часть. Перед ней посмотрели живые книги с импортом (только чтение).
Что из них следует: таможня платится в день декларации с готовой разбивкой
(сборы, пошлина не всегда, ƏDV импорта) — «Gömrük ödənişi…» (D212) устроен верно; заранее
платится только терминал, его e-qaimə приходит через месяц одна на несколько деклараций; номер
qısa в себестоимость не идёт; месяц зачёта ƏDV импорта бывает позже оплаты; у этого клиента
импорт — основные средства, а не товар.

Сделано (D-new-expense-for-purchase):
- миграция 0072 `inventory_expense_targets`: строка расхода → покупка товара;
- покупка: колонка «К покупке» у строк «Əlavə xərc», список покупок с поиском по номеру;
  «Разделить строку» сохраняет покупку у обеих частей;
- «Расходы по партии»: сказанное о выбранных покупках отмечено само;
- удаление покупки товара оставляет её расходы ждать без покупки.

Проверено тестами и скриншотом формы; вживую на Windows не смотрели.
