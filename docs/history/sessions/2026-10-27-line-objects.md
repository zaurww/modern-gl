# 2026-10-27 — `claude/line-objects`: много строк покупки разом

Пользователь попробовал D172 на 15 строках (5 ОС, 10 МБП): объект ОС, разошедшийся по всем
строкам, пришлось менять в каждой. Сделано (D173, уточняет D172): субконто больше не
расходится; выделенные строки берут одно значение списка; пустой объект ОС/НМА открывается
с названием строки; кнопка «Объекты по названиям строк» создаёт объекты разом
(`Ledger.add_named_values`). Окно — то же «Строки — товары» (`NewNamesDialog`, `wording`).

После проверки пользователем (D174, уточняет D173): статья затрат снова разносится по
строкам своего счёта (ОС — нет); Ctrl+V вставляет в «Hesab» и субконто, одно значение — во
все выделенные строки; вставка больше не ставит склад строке-«Счёт» (ошибка «sətir 25:
xidmətin anbarı olmur»).
