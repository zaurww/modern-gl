# 2026-10-25, ветка `claude/eqaime-codes` (D137)

- Пользователь: в e-qaimə с портала есть код товара или услуги; налоговая в письмах о
  несоответствии ссылается на него — «нужно скачивать… по мере необходимости получить по
  разрезу этих кодов отчёты»; уточнил: это именно код товарной группы.
- Разбор: код (`productGroup.code`) уже читается при импорте (`eqaime/parsing.py`), но служит
  лишь признаку услуги («99…») и не сохраняется; `eqaime_portal` хранит одну шапку.
- Решение D137 (`docs/DECISIONS.md`): таблица строк e-qaimə с портала рядом с шапкой,
  отчёт «По кодам товарных групп» в «Все отчёты», учёт и номенклатура без изменений;
  код по умолчанию у номенклатуры — отложено до случая (D135).
- Только решение и документы, код не писался — по просьбе пользователя. В STATUS — одной
  строкой в «Дальше». Слито в `master` после D136 (параллельная сессия) как D137.
