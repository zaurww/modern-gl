# 2026-11-27, ветка asset-units (D232)

Пользователь: «по e-qaimə купили 3 одинаковых основных средства… эти 3 объекта попадают как
один?», «в qaimə это указано одной строкой», «кому-то нужен поштучный учёт. Например сеть
ресторанов, 20 кофейных аппаратов в разных точках».

Сделано (D232): по умолчанию строка — партия (один объект с количеством N, как было); F8 на
строке объектов с целым количеством ≥ 2 — кнопка «По одной штуке — N строк»: N строк по одной
штуке «название №1…№N», сумма и ƏDV поровну (остаток копеек — в последней), затем сразу
«Объекты по названиям строк». Хранение и проводки не менялись.

Отвергнуто: одна строка документа с N проводками (нужна своя таблица; строки по одной дают
каждой штуке свою точку).

Проверено: `tests/test_asset_units.py` (1 000,00 / 3 = 333,33 + 333,33 + 333,34; ƏDV 60,00 × 3),
полный прогон, ruff, pyright. Вживую не смотрели, скриншоты не снимались (диск D заполнен).

Дальше (предложено, не начато): карточка ОС, амортизация (налоговая по группам / линейная —
ждёт решения пользователя), выбытие части партии по количеству, порог 01 / 12 при покупке.
