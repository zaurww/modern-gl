# 2026-11-04 — `claude/directory-objects`: справочник объектов — признак справочника

Вопросы пользователя по ходу загрузки закупок с портала: куда провести брокера до
прихода товара (на 15 без субконто, тип «Запасы»; потом «Расходы по партии» → «Из
проводки», D33); кондиционер с монтажом — обе строки на один объект справочника (08 или
01), амортизация увидит 1054; десять строк малоценки на свой счёт 12 — элемент из первой
строки расходился по всем, потому что справочник пользователя считался категорией.

Сделано (D194, уточняет D173/D174): признак справочника «Объекты: у каждой строки
покупки свой элемент» (`subconto_kinds.per_line`, миграция 0063) вместо списка кодов в
коде; включён у ОС и НМА, включается в «Справочники» → «⋯». Теги (D64) вынесены из
`ledger/subconto.py` в `ledger/tags.py` отдельным коммитом (предел 500 строк класса).
Файл-образец схемы 0063 для теста обновления; кадр `8b3_directory_objects` в скриншотах.

Отложено по просьбе обсудить позже: в окне загрузки e-qaimə при новом названии строки
брать последний счёт услуг поставщика (как форма покупки, D76); сортировка по заголовкам
и период в списках «Alış»/«Satış», журнале, банке; «только черновики» — сортировкой по
статусу или словом в поиске.
