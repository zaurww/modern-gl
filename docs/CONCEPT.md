# Рамка проекта

Главные концептуальные решения, на которых стоит всё остальное. Читается в начале каждой
сессии. **Рамка меняется только явным решением пользователя:** новая запись в
`docs/DECISIONS.md` и правка этого файла в том же коммите. Если просьба или идея с рамкой
расходится — сначала сказать об этом пользователю, а не обходить молча.

## 1. Зачем программа
- **Инструмент для собственной работы владельца-бухгалтера, не продукт на продажу (D30;
  заменяет коммерческую цель D25).** Мерило — удобство в ежедневной работе, а не рынок.
- **Взять простотой:** быстро, просто, легко настраивается. Новая функция не должна делать
  обычную работу сложнее — сложное прячется, пока не нужно.
- Один бухгалтер на одном рабочем месте ведёт несколько независимых фирм; локально,
  без интернета (кроме портала e-taxes и курсов ЦБА).

## 2. Учётная модель
- **Проводка — пара Дт/Кт + сумма, как в 1С 7.7 (D1); субконто — часть ядра, до 3 на
  счёт (D2).** Привычки 1С 7.7 сохраняем, советские понятия — нет (вид счёта A/P/AP
  убран, D17).
- **Деньги — целые копейки (`int`), никаких `float` (D3).** Количества — тоже целыми.
- **Проведённое не исправляется без следа:** в открытом периоде правка на месте, отмена
  проведения или удаление с полной копией в журнале действий (D19, D32); в закрытом — только
  сторно (D5).
- **Слой ≠ книга (D7):** документ лежит в одном слое (общий, МСФО, налог), книга — набор
  слоёв. Параллельные книги включаются настройкой (D63).
- **План счетов настраивается:** код необязателен, счёт — это id (D22); класс и тип счёта
  задают отчёты и счета по умолчанию (D14, D35, D89) — программа не полагается на коды.
- Эталон правильности — примеры, посчитанные вручную; выгрузки из 1С не будет (D8).

## 3. Данные
- **Файл на компанию (D18):** компания — единица передачи, копии и архива. Один файл —
  один пользователь за раз; живой `.gl` не открывают с сетевого или облачного диска (D25).
- **Один источник правды (D72):** проводки — бухгалтерская правда; документ модуля —
  первичный документ, проводки из него строятся заново (D101). Производное пересчитывается,
  повторный импорт не создаёт дублей.
- **Путь к серверу открыт, но не пройден:** `company_id` и составные ключи везде, SQL общий
  для SQLite и PostgreSQL, запись только через `application` (D24, D77). Переходить —
  только когда понадобится совместная работа нескольких людей с одной фирмой.
- Данные не теряются: резервные копии с полной проверкой, восстановление (D74, D97).

## 4. Модульность
- **Ядро (главная книга) самодостаточно; модули — по желанию (D30, D71).** Склад, покупки
  и продажи, банк, конвертация, e-qaimə, будущие ОС, касса, зарплата связаны с ядром только
  проводками и справочниками. Зависимость — только «модуль → ядро».
- Модуль — свой пакет и свои таблицы; заявляет о себе через общие точки: `document_owners`
  (D75), `rebuild_postings` (D101), строки «Bu gün» и команды Ctrl+K.
- Внешние программы (etax-ext, учёт ОС) подключаются импортом документов, а не общей базой.

## 5. Интерфейс
- **Дизайн — главный приоритет:** светло, много воздуха, боковая панель вместо вкладок,
  один акцентный синий, без сеток «как в Excel» (ориентир — Things; D86).
- **Уют (D106):** всё делается с клавиатуры, Enter идёт дальше; каждое число ведёт к
  документу; одинаковое работает одинаково везде; программа помнит выбор; опасное — с
  «Geri al», а не с вопросом.
- Интерфейс азербайджанский (по умолчанию) и русский (D12); с пользователем — по-русски.

## 6. AI
- AI читает и готовит черновики; **проводит только человек** (D83, D84).

## 7. Как ведётся работа
- Тест с цифрами, посчитанными вручную, на любое изменение учёта; CI зелёный.
- **Маленький код (D70)** и **короткие документы (D109)** — пределы проверяют тесты
  (`test_code_size.py`, `test_docs_size.py`); сначала разделить или сократить, потом
  добавлять.
- Решения пользователя — в `docs/DECISIONS.md`, с его словами и датой.

## 8. Чего не делаем (без нового решения пользователя)
- Продажу и функции «для рынка» в ущерб простоте.
- Одновременную работу нескольких людей с одним файлом; общий файл в сети.
- Выгрузку из 1С 7.7; `float` для денег; правку проведённого без следа.
- Модуль, без которого ядро не работает; знание ядра о таблицах модулей.
- Автоматическое проведение документов AI.
