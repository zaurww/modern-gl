# D235 — Оплата нескольких e-qaimə не в полную сумму: каждой сначала её сумма без ƏDV
Статус: принято (уточняет D78, D145)
Дата: 2026-11-27

## Контекст
ELV, SR LOGISTICS: одна оплата 835,31 за две e-qaimə (590,28 и 395,38 с ƏDV), ƏDV — отдельно
через депозит. Раскладка «по очереди до полной суммы» дала первой 590,28, второй 245,03;
переводы ƏDV (90,04 и 60,31) легли каждый на свой номер — первая переплачена на 90,04,
вторая недоплачена. Верно: 500,24 и 335,07.

## Решение
Оплата из файла банка (не ƏDV), которая не покрывает свои e-qaimə целиком: каждая получает
долг без ещё не оплаченного ƏDV, по очереди; остаток — на их ƏDV, по очереди (`net_first`).
Полная оплата и оплата одной e-qaimə — как раньше. И для названных в назначении, и для
разложенных «по старым».

## Последствия
`bank/operations.net_first`, `file_import._without_vat_first`; тесты — `test_bank_parties.py`.
Уже проведённые операции не меняются — поправить руками. Ручная строка банка — одна
e-qaimə на строку, не затронута.
