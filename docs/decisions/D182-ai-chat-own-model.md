# D182 — Встроенный AI-чат — каждый подключает свою модель (на будущее)
Статус: принято (уточняет D83, шаг 4)
Дата: 2026-10-29

## Контекст
Пользователь: «можно сделать интерфейс откуда можно подключаться к ai и писать запросы прямо
там?», «а что если каждый пользователь сам подключает к своей ai модели?», «оставим на
будущее, спланируем». Сейчас AI — снаружи, через MCP (D83, D84).

## Решение
Отложено; когда возьмём — так:
- Модель выбирает и оплачивает пользователь: «Провайдер / Адрес / Ключ / Модель», два
  формата — Anthropic и OpenAI-совместимый (OpenAI, Gemini, OpenRouter, Ollama…). Не
  настроено — чата нет.
- Ключ — на компьютере пользователя, не в `.gl`; данные в облако — по включению у компании.
- Инструменты — из `assistant/`; запись — только черновики (D84).
- AI знает открытую страницу; рядом с ответом — какие отчёты он запрашивал, со ссылками.
- Вид — панель справа «Спросить AI» (D86).
