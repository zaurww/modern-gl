# D-new — Решения — файл на решение в формате ADR
Статус: принято
Дата: 2026-10-27

## Контекст
`docs/DECISIONS.md` — 252 КБ одной markdown-таблицей, 152 строки до 7 181 символа: в diff
и при чтении неразборчиво, параллельные ветки конфликтовали в конце файла, отмена —
зачёркиванием.

## Решение
Одно решение — один файл `docs/decisions/D<nnn>-<slug>.md` (ветка `claude/audit-docs`,
аудит документации): шапка `# D<n> — заголовок`, «Статус» (принято | заменено D<n> |
отменено), «Дата», разделы «Контекст», «Решение» (слова пользователя), «Последствия»
(где живёт в коде, какой тест). Только добавление, номера не переиспользуются; отменённое
получает статус, а не зачёркивание. Новое решение в ветке — `D-new-<slug>.md`, номер —
при слиянии (D131). Индекс `README.md` генерируется, «Ещё не решено» — `OPEN.md`;
`DECISIONS.md` — указатель. Старые решения перенесены без потерь текста
(`scripts/split_decisions.py`), «Контекст» у них — «—».

## Последствия
Код: `scripts/split_decisions.py`, `scripts/decisions_index.py`, `tests/test_decisions.py`
(форма файла, номера подряд, индекс актуален, ≥ D109 — контекст и решение ≤ 1 200 символов).
