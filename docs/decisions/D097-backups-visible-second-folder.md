# D97 — Резервные копии на виду и вторая папка
Статус: принято
Дата: —

## Контекст
—

## Решение
**Резервные копии на виду и вторая папка** (сессия 39, п. 5 «Чего нет по брошюре»). Копии по-прежнему делаются при закрытии компании, если что-то изменилось (D74), по 30 на компанию. (1) **На виду:** на «Bu gün» — раздел «Резервная копия» («Последняя копия · дата время» или «Копий ещё нет — копия делается при закрытии компании»; при просмотре снимка не показывается), щелчок открывает окно «Резервные копии…» (меню компании): когда и где последняя копия, «Показать папку», «Сделать копию сейчас». `Session.last_backup` — окно знает папку копий, страница — нет. (2) **Вторая папка** (флешка, облачная папка): настройка этого компьютера (`QSettings` `backup_mirror`), не файла компании — путь к флешке у каждого свой. `Workspace.mirror`; `Workspace.backup_now` пишет копию в свою папку и её же — в `<вторая папка>/<Компания>/` (`backup.mirror`: через `.part`, тоже 30 последних). Вторая папка недоступна (флешка вынута) — первая копия остаётся, пользователь видит предупреждение.

## Последствия
Код: `<вторая папка>/<Компания>/`.
