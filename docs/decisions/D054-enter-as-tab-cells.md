## Решение
**Ввод с клавиатуры: Enter = Tab, ячейка всегда открыта, новое имя — из списка** (сессия 16, по жалобе пользователя на путаницу Tab/Enter в журнале). В форме документа (и во всех таблицах ввода: проводки, начальные остатки, шаблоны, склад, расходы по партии) Enter и Tab делают одно и то же — следующее поле, Shift+Tab — назад. Шапка: содержание → дата (одно поле: Tab не ходит по дню/месяцу/году, цифры «17042026» переходят по частям сами, `widgets.DateEdit`) → книга → первая ячейка. Ячейка, в которую пришли с клавиатуры, сразу открыта для ввода — виден курсор (`postings.edit_current`). Имени нет в справочнике субконто — последним пунктом списка «+ Əlavə et «…»» (единственным, если совпадений нет: Enter добавляет без окна и идёт дальше). Окно «Добавить?» осталось только для ввода при закрытом списке; курсор ждёт ответа в ячейке: «Bəli» — дальше, «Xeyr» — назад в ячейку с введённым текстом.
