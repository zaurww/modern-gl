# D63 — Параллельные книги включаются на компанию; без них книги не видно
Статус: принято
Дата: 2026-10-21

## Контекст
—

## Решение
**Параллельные книги включаются на компанию; без них книги не видно** (сессия 19, обсуждение «простота против настройки»; уточняет D7). Модель слоёв остаётся: общий слой + слои корректировок (МСФО, налог), книга = сумма слоёв; полностью параллельных книг с дублированием проводок не будет. Флаг `companies.parallel_books` (миграция 0029; включён у компаний, где уже есть документы не в общем слое). Пока выключен — нет поля «Книга» в документе (Enter идёт с даты сразу в первую ячейку), переключателя книг и названия книги в отчётах, колонки «Книга» в журнале. Включается в меню компании «Параллельные книги (МСФО, налог)»; документ, записанный в слой корректировок (в т.ч. импортом), включает флаг сам; выключить нельзя, пока такие документы есть. **Дальше (не сейчас):** таблица `books` (книга = набор слоёв, свои слои) — когда понадобится книга, которой нет среди трёх; модули сами пишут разницы в слои корректировок (ОС — налоговая амортизация в `tax_adj`). **Не делать:** свой план счетов на книгу (различия отчётности — формами по типам счетов, D35), правила «какой документ в какую книгу» (непризнанное налогом — сторно в `tax_adj`).
