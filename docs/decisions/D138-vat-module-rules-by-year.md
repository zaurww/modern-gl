## Решение
**Модуль ƏDV: зачёт ƏDV покупок по версии правил своего года; отчёт «ƏDV к зачёту»** (ветка `claude/vat-report`; пользователь: «можем начать потихоньку разрабатывать НДС отчёт, модуль отдельный», «зачёт по декларациям по импорту происходит сразу по оплате», частичная оплата — «долей от оплаченного»; устройство — `docs/REPORTING.md`, «Модуль ƏDV»; применяет D31, D135). Пакет `application/vat` (модуль, `MODULE_CODE`): `rules` — версии с `valid_from`, период раньше первой — ошибка; `facts` — факты покупки по номеру из проводок (D120): e-qaimə, основная сумма, ƏDV на `input_vat`, оплаты по дням, ƏDV — с `vat_deposit` или таможне; `credit` — события зачёта: min(оплаченный ƏDV, доля оплаченной суммы), не раньше e-qaimə, декларация — по оплате ƏDV. `reporting/vat.py` и страница `VatCreditPage` («Все отчёты» → «Налоги и e-qaimə»): день, номер, контрагент, ƏDV, к зачёту, зачтено ранее, ждёт; итоги в подвале; двойной щелчок — документ. Ядро не меняется. Тесты с цифрами вручную — `test_vat_credit`.
