## Решение
**Модуль «Банк» (Bank) — банковская операция как документ модуля, сначала ручной ввод** (сессия 13, миграция 0025: `bank_operations`, `bank_operation_lines`). Раздел в блоке «Модули» после «Alış» и «Satış» (Ctrl+B): слева банковские счета с остатком на конец периода, справа выписка выбранного — все документы, двигавшие счёт (из проводок: журнал, конвертация, операции банка), по документу строка, приход / расход / остаток, черновики операций — серым, без остатка; двойной щелчок открывает первичный документ. **Банковский счёт** = счёт типа `bank` или `vat_deposit` (или без типа, но со справочником «Банковские счета») + элемент справочника; элемент показывается под счетами, где он использован, а новый — под первым счётом, подходящим по валюте (USD — под 52). Суммы выписки — в валюте элемента. **Операция:** «Приход / Расход» (Mədaxil / Məxaric), дата, банковский счёт (валюта — из элемента, D28), вид (поставщик, покупатель, налоги, зарплата, комиссия банка, перевод между своими счетами, прочее), контрагент (поиск по названию и VÖEN; заполняет позицию контрагента в каждой строке, договоры — только его), назначение платежа (= содержание документа; пустое — по виду: «Оплата поставщику X»), референс выписки (`find_bank_operation` — задел под импорт, как D37). **Строки** — расшифровка платежа: счёт, его субконто, e-qaimə (закрывает её в отчёте «E-qaimələr», D38), сумма; «+ Комиссия банка» — строка на счёт роли `bank_fee` со статьёй «Комиссия банка». Счёт строки подсказывается «как в прошлый раз» для этого контрагента и направления (последняя операция банка, иначе последняя проводка «банк ↔ счёт с этим контрагентом», `last_lines`), иначе — первый счёт типа вида (60, 62, 68, 70; для перевода — другой банковский счёт той же валюты). **Проводки** (строит документ): расход — Дт счёт строки / Кт банк, приход — Дт банк / Кт счёт строки, по строке; в валюте — по курсу ЦБА на дату, сумма в валюте в проводке; нет курса — плашка «Загрузить курс ЦБА». Исправление — как у конвертации (D32): проведённая правится на месте с тем же номером, «Отменить проведение», удаление; журнал её проводки не трогает. **ƏDV depozit hesabı (D41):** проводится только вид «поставщик», «покупатель», «налоги», «перевод» (черновик — любой); в форме остальные виды скрыты. «Конвертация валюты» переехала из журнала в этот раздел. Позже: импорт выписок (сначала EDV DH — нужен образец), API банков, касса.
