## Решение
**ƏDV DH с портала — сначала просмотр, итог в окне** (сессия 43; пользователь: «как alış и satış нужно сверяться, чтобы ничего не забыть»; уточняет D112, D115). После загрузки ничего не записано: окно показывает каждую операцию — дата, контрагент, VÖEN, сумма, «Станет» (счёт, e-qaimə), состояние (будет проведена / черновик: причина / введена вручную — будет связана / уже есть), галочки. Просмотр — тот же импорт, откатанный (`Ledger.bank.preview_vat_deposit`): просмотр и запись не расходятся. «Провести» (синяя, по умолчанию — по D112 выписка — факт) или «Создать черновики» — только отмеченное; период помнится, только если ничего не снято. Итог — в окне, не тостом: двойной щелчок открывает документ; под строками остаток портала, программы и «после загрузки». День, загруженный до его конца, не считается загруженным (`PortalLoad.closed_to`): окно предлагает его снова. `desktop/bank_page/deposit_rows.py`.
