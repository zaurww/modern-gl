# D143 — Сверка поступлений с e-qaimə — по покупателю, аванс раскладывается на e-qaimə по старшинству; предупреждения, где ƏDV начислен не так

## Решение
**Сверка поступлений с e-qaimə — по покупателю, аванс раскладывается на e-qaimə по старшинству; предупреждения, где ƏDV начислен не так** (ветка `claude/vat-reconcile`; этап 3а; пользователь: «ручной контроль будет в любом случае», «по одному авансу можем выписать несколько фактур»). Отчёт «Поступления и e-qaimə» (`reporting/vat_receipts.py`): строка на покупателя, под ней его e-qaimə и «аванс» (деньги без номера); за период — поступило по e-qaimə, без номера, на депозит ƏDV, выписано (стоимость, ƏDV), начислено ƏDV (D142, итог = «ƏDV продаж к уплате»); на конец периода с начала — аванс и неоплаченное. Деньги с номером платят свою e-qaimə, остальное — e-qaimə покупателя от старшей (как банк, D62), остаток — аванс. Предупреждения: ƏDV, начисленный с денег без номера (18% навсегда), больше ƏDV оплаченных ими e-qaimə и 18% открытого аванса — «e-qaimə без ƏDV при авансе» или «ƏDV пришёл на расчётный счёт?»; деньги с номером больше стоимости e-qaimə, а на депозите её ƏDV не хватает — «ƏDV пришёл на расчётный счёт, не на депозит». Двойной щелчок: e-qaimə — документ, покупатель и аванс — карточка субконто (D126); номер в оплате правится в банке (D67).
