# D40 — Начальные остатки — одна таблица, разница на счёте 00
Статус: принято
Дата: 2026-10-20

—

## Решение
**Начальные остатки — одна таблица, разница на счёте 00** (уточняет D39). Одна таблица как ОСВ: счёт, субконто, сумма в колонке «Дебет» или «Кредит» (новая строка встаёт на нормальную сторону счёта: 60, 80, 02 — в «Кредит»); вставка из Excel понимает заголовки «Счёт / Дебет / Кредит / Сальдо Дт / Сальдо Кт». Итоги могут не совпадать: остатки вносятся частями, разница остаётся на видимом счёте **00 «Ввод начальных остатков»** (как 00 в 1С 7.7) и видна в ОСВ. Молча на капитал разница **не** относится — это прячет опечатки (опыт «Opening Balance Equity» в QuickBooks); кнопка «Разницу — на счёт…» добавляет видимую строку, счёт выбирает бухгалтер (предлагается счёт типа «Нераспределённая прибыль», если он один). На 00 проводит только документ начальных остатков — это проверяет `Ledger`, поэтому его нельзя сторнировать.
