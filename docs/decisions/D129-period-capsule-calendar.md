## Решение
**Выбор дат — капсула периода и один календарь дней** (сессия 55; пользователь: «не очень нравится дизайн выбора дат»; по макетам выбрал «одна капсула» и «календарь дней», «месяцы… английской 3-х буквенной аббревиатурой — так аккуратно и коротко»). Поле периода — одна капсула `‹ текст › │ 📅` вместо поля и трёх отдельных иконок; щелчок по тексту — ввод, 📅 — окно (уточняет D105). В окне периода справа — календарь дней месяца: первый щелчок — начало, второй — конец, применяет «Готово»/Enter; поля «С … по …» и календарь идут вместе. Месяцы в сетке — `Jan … Dec` на любом языке, кварталы — «1 кв». Системный `QCalendarWidget` (номера недель, красные выходные, английские подписи) заменён своим `desktop/day_calendar.py` — один для поля даты и для окна периода: ← → ↑ ↓ PgUp PgDn, Enter, «Сегодня», границы `setDateRange`.
