# D-new — Обновление из программы: раз в день спросить GitHub, тихая установка
Статус: принято
Дата: 2026-11-03

## Контекст
Коллега-тестировщик не технарь: скачивать установщик с GitHub и ставить его руками после
каждой правки — работа пользователя. Слова пользователя: «коллега заметил, я поправил, у него
появился знак UPDATE, нажал — готово».

## Решение
- **Раз в день** при запуске установленная программа (PyInstaller, `sys.frozen`) спрашивает
  у GitHub последний Release (`/releases/latest`, 8 с, в фоне, молча при любой ошибке). Из
  исходников (`uv run modern-gl`) — не спрашивает. День проверки — в настройках программы.
- **Строка внизу боковой панели** «Вышла версия 0.1.4 — обновить» (плоская кнопка акцентным
  цветом, D86: ждущее громче); иначе ничего не показывается.
- **По щелчку** — скачать setup.exe во временную папку (показан процент), запустить тихо
  `/SILENT /CLOSEAPPLICATIONS` через `cmd … /wait … & start modern-gl.exe`: установщик сам
  закрывает программу (D189, `CloseApplications=yes`) и после установки программа запускается
  снова — обновлённая или прежняя, если установку отменили. Файлы компаний не трогаются.
- Сравнение версий — по числам (0.1.10 новее 0.1.9); без подписи кода SmartScreen может
  переспросить при первом запуске новой версии.

## Последствия
`infrastructure/github_releases.py` (сеть), `application/updates.py` (смысл: новее, раз в
день, команда установки), `desktop/updater.py` (фон, строка, запуск), `sidebar.new_version`,
`preferences.UPDATES_CHECKED`, `app.py`; перевод `i18n_az/updates.py`; `tests/test_updates.py`.
