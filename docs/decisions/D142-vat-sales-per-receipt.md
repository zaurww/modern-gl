# D142 — ƏDV продаж — по каждому поступлению денег: большее из ƏDV на депозите и ƏDV поступившей стоимости
Статус: принято
Дата: 2026-10-25

## Контекст
—

## Решение
**ƏDV продаж — по каждому поступлению денег: большее из ƏDV на депозите и ƏDV поступившей стоимости** (ветка `claude/vat-liability`; этап 3; НК ст. 166 — 166.1, 166.5–166.7 в редакции закона 1033-VIQD, текст из `zaurww/consulting`; правило «30 дней» отменено). Пользователь: «в январе поступило 100 основной и 14 НДС — НДС от 100; в феврале 3 — ничего, всё начислено в январе»; «в январе только 10 НДС — обязательство 10; в феврале 100 — ещё 8». Отсюда: обязательство на дату = max(ƏDV, поступивший на депозит; ƏDV поступившей стоимости — доля ƏDV e-qaimə, до e-qaimə 18%), не больше ƏDV e-qaimə; событие дня — прирост, может быть отрицательным (возврат денег, e-qaimə без ƏDV после аванса). Деньги без номера — аванс по контрагенту (в «classic» нет 62.2 — аванс на 62); зачёт аванса (Дт 62.2 / Кт 62) денег не двигает и обязательства не даёт. Ставка — в версии правила (`LiabilityRule`, с 2024 года).
