# D104 — Отчёт «для Excel»: плоская таблица, числа — числами
Статус: принято
Дата: 2026-10-23

## Контекст
—

## Решение
**Отчёт «для Excel»: плоская таблица, числа — числами** (сессия 40; пользователь: «у Excel свой язык, нужен отчёт оптимальный для Excel»). «⋯ → В Excel…» на любом отчёте (`desktop/reports_page/export.py` берёт колонки и строки страницы; файл пишет `infrastructure/report_file.py`): таблица с A1, одна строка шапки (закреплена, автофильтр), без объединённых ячеек, цветов и зебры; суммы — числа в манатах (формат `#,##0.00`, минус красным), сальдо «Дт/Кт» — числом (Дт +, Кт −; `Column.value`), коды — текстом; глубина строки — группировка строк Excel (+/−) и колонка «Уровень»; название, компания, период — на втором листе «Параметры»; файл открывается сразу. Ctrl+C — выделенные строки (или весь отчёт) табуляцией, десятичный разделитель системы. «⋯» в шапке всегда последний.

## Последствия
Код: `desktop/reports_page/export.py`, `infrastructure/report_file.py`.
