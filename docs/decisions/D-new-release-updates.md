# D-new — Релиз и обновления: версия в одном месте, установщик, тег собирает
Статус: принято
Дата: 2026-10-29

## Контекст
Первый релиз для тестировщиков; вопрос — как обновлять после ошибок. Сборка по тегу была
(D161), но без установщика, версии в программе и порядка выпуска. Репозиторий приватный.

## Решение
- Версия — только в `pyproject.toml` (`uv version`); программа берёт её из метаданных
  (`modern_gl.__version__`): низ боковой панели, журнал при старте, первая строка окна «Ошибка».
- Установщик Inno Setup для одного пользователя, без прав администратора; новый setup поверх
  старого обновляет на месте (тот же `AppId`, прежний `_internal` удаляется). Файлы компаний
  не трогаются: новая версия обновляет их с копией (D148), старая новый файл не откроет (D159).
- Выпуск: `scripts/release.py <версия> --push` — раздел в CHANGELOG, версия, коммит, тег;
  тег запускает `release.yml` (PyInstaller + ISCC → setup и zip в Release); тег = версия.
  «Run workflow» вручную — сборка без тега.
- Раздача: setup скачивает пользователь и отправляет сам; проверка обновлений из программы —
  когда будет публичный адрес. Ошибки — текст окна «Ошибка» или `log/modern-gl.log`.
- Иконка — `scripts/app_icon.py` из темы (акцент, Lucide «scale»).

## Последствия
`modern_gl/__init__.py`, `logs.py`, `crash_dialog.py`, `sidebar.py`, `app.py`; `packaging/`,
`release.yml`, `scripts/release.py`, `scripts/app_icon.py`; тест `tests/test_release.py`.
