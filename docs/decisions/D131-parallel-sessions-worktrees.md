## Решение
**Параллельные сессии — каждая в своём worktree, номера при слиянии, свои файлы вместо общего конца** (сессия 2026-10-24 `claude/parallel-sessions`; пользователь: «если работают несколько параллельных сессий, как организовать процесс, чтобы тебе потом было легко», «давай»). Было: две сессии «55» и две «56», конфликты в конце `sessions.md`, `DECISIONS.md`, `i18n_az.py`, чужое незакоммиченное в основной папке, `master` уходил вперёд за 16 минут прогона. Правила — `CLAUDE.md`, «Параллельные сессии»: worktree и ветка с первого шага, основная папка — только для слияния; решение в ветке — `D188`, номер — при слиянии; запись сессии — файл в `docs/history/sessions/` (сессии 41–57 — `sessions-41-57.md`); переводы — пакет `i18n_az/`, файл на функцию (`core` — всё до сих пор, `exchange` — D130), ключ — в одном файле (`test_i18n`); слияние по одной ветке после прогона `pytest -n auto` (pytest-xdist, и в CI).

## Последствия
Код: `i18n_az.py`, `docs/history/sessions/`, `i18n_az/`, `test_i18n`.
