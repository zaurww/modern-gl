# D216 — Касса в разделе «Банк и касса»
Статус: принято (развивает D47, D78)
Дата: 2026-11-12

## Контекст
Наличные вводились проводкой. Пользователь (2026-11-12): касса — в разделе «Банк», печатать
приходный и расходный ордер и кассовую книгу, подотчётных лиц — позже.

## Решение
- Счёт типа «Касса» (50) — место банка: та же форма и виды, кроме «Комиссии банка».
- В списке — когда по ней было движение; своя группа первой. Сверки с банком, «+ Выписки»,
  файлов, реквизитов, депозита ƏDV нет; выписки по дням — листы книги («День»).
- Раздел — «Банк и касса».
- Документы — «Приходный / Расходный кассовый ордер» (миграция 0069); номер — номер документа,
  нумерация по видам ждёт D213.
- Excel на языке документов: ордер по любой проведённой строке кассы, у приходного — квитанция;
  сумма прописью az/ru; книга — лист на день, итоги формулами (D215).
