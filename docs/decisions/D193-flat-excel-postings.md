# D193 — «Проводки для Excel»: плоская таблица для сводной, без отчётов в программе
Статус: принято
Дата: 2026-11-03

## Контекст
Пользователь о Logo ERP: окно с фильтрами и «excel-friendly» отчёты, где удобно строить
сводные таблицы; SQL-доступ там же. Решено: SQL-контракт (представления) — не сейчас,
без реального случая (D135); сводные таблицы программа не строит — «просто полученный
Excel должен быть плоским и удобным для получения pivot».

## Решение
Отчёт «Проводки для Excel» (группа «Бухгалтерские», Ctrl+K): период и книга, список
проводок на экране, строка проверки «Дт = Кт = … ✓ совпадает с оборотом ОСВ», одна синяя
кнопка «В Excel». Файл — две плоские таблицы Excel (ListObject, без итогов и уровней):
**«Проводки»** — строка на проводку: дата, год, месяц, квартал, №, документ (модуль),
содержание, счёт / название / класс / счёт верхнего уровня обеих сторон, **субконто
колонками по видам** («Контрагенты», при надобности «· папка», «· теги»), сумма, валюта,
книга, e-qaimə, кто провёл, ID документа; **«Стороны»** — две строки на проводку (Дт +,
Кт −) и строки **остатков на начало** по счёту и субконто, так что сумма в сводной по
счёту даёт конечное сальдо. Даты — датами, суммы — числами. Фильтров кроме периода и
книги нет: отбирает сводная. Склад (количество, цена), aging, SQL-представления — отдельно.
