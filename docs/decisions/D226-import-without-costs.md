# D226 — «Bu gün»: импорт, до которого не дошли доп. расходы
Статус: принято
Дата: 2026-11-26

## Контекст
Пользователь случайно заметил: импорт декабря 2025, а e-qaimə местного брокера на əlavə
xərclər пришла 21.01.2026. Ничто об этом не напоминало: «Расходы ждут партии» (D211) молчат,
пока e-qaimə не загружена.

## Решение
- Расход признаётся датой e-qaimə (январём): «Расходы по партии» делят его на остаток и на уже
  проданное, отчёт «Əlavə xərclər» показывает его у декларации независимо от даты (D85). Сумма
  мала против партии; начисление декабрём — вручную, когда сумма существенна. Отдельной функции
  нет.
- «Bu gün» — строка «Импорт без доп. расходов» («Əlavə xərcsiz idxal»): проведённые покупки
  товара по таможенной декларации, на строки которых нет ни одной проведённой «Расходы по
  партии». Черновик партии не считается. Со дня покупки, без отсрочки; ведёт в «Склад».
- Ничего не хранится: считается из документов. Импорт, у которого расходов и не будет,
  остаётся в строке — отметки «расходов нет» пока нет.

## Последствия
`reporting/inventory/costs.py` (`imports_without_costs`), `application/attention.py`. Миграции
нет. Тесты — `tests/test_waiting_expenses.py`. Не ловит: расходы взяты частично (таможня есть,
брокера нет).
