# D227 — Импорт продаж e-qaimə: название товара помнится для всех покупателей
Статус: принято
Дата: 2026-11-26

## Контекст
Перед первой загрузкой продаж с портала: названия в e-qaimə могут немного отличаться от
названий товаров в программе. Импорт помнил, чем стала строка («как в прошлый раз»), только по
контрагенту — верно для покупок (названия поставщика), но в продаже названия свои: одно и то же
название пришлось бы выбирать заново у каждого нового покупателя.

## Решение
- Строка продажи (и возврата от покупателя), у которой нет своей истории по этому покупателю:
  товар, которым это название стало в последней продаже любому покупателю. Услуги — нет.
- Порядок: свой прошлый выбор по покупателю → общий по продажам → товар с таким названием.
- Сравнение прежнее — `fold` (регистр, азербайджанские буквы). Похожие названия (пробелы,
  знаки — D209) не подставляются: отложено до первых живых данных.
- Покупки не меняются: память по поставщику.
