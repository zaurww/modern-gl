# D32 — Проведённый документ правится на месте, как в 1С
Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**Проведённый документ правится на месте, как в 1С** (смягчает D19, заменяет «склад только по порядку дат» из D26). В открытом периоде проведённый документ GL открывается редактируемым; «Провести» (и Ctrl+S) перепроводит его одной транзакцией (`Ledger.repost`), номер сохраняется, старое содержимое — в журнале действий. Сторно, сторнированный, закрытый период и проводки склада — только чтение. Из журнала и отчётов проводки складского документа открывают **сам складской документ**. Складские документы проводятся в последовательности (дата, приход раньше расхода в пределах дня, номер): правка, проведение задним числом, отмена и удаление снимают с проведения более поздние документы и проводят их заново (`Inventory.reposting`), связанные документы GL переписываются с прежними номерами; если что-то не проходит (уходит в минус) — откат всего с названием документа. Строки складского документа сохраняют id при правке (на них ссылается landed cost).
