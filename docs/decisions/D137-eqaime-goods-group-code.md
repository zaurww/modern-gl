# D137 — Код товарной группы e-qaimə — хранить строки портала, отчёт по кодам при надобности
Статус: принято
Дата: 2026-10-25

## Контекст
—

## Решение
**Код товарной группы e-qaimə — хранить строки портала, отчёт по кодам при надобности** (ветка `claude/eqaime-codes`; пользователь: «иногда налоговая пишет письмо о несоответствии, ссылаясь на эти коды… по мере необходимости… получить по разрезу этих кодов отчёты», «налоговая ссылается именно на код товарной группы»; уточняет D53). Было: портал отдаёт код в каждой строке (`productGroup.code`), импорт лишь отличает по нему услугу («99…») от товара, дальше код теряется — `eqaime_portal` хранит одну шапку. Решено: (1) таблица строк e-qaimə с портала рядом с шапкой — название, код, единица, количество, сумма без ƏDV, ƏDV; пишется при каждом чтении деталей, импортирована фактура или нет (письмо налоговой — о данных портала); код — строкой как есть, без справочника; (2) отчёт «По кодам товарных групп» в «Все отчёты»: период, покупки или продажи, итоги по коду (фактур, без ƏDV, ƏDV), раскрытие до фактур; в повседневных экранах нет; (3) учёт, номенклатура и формы не меняются — код номенклатуры свой (один налоговый код — много товаров). Отложено до случая (D135): код по умолчанию у номенклатуры для своих e-qaimə. Таблица — модуля e-qaimə (`MODULE_TABLE`).
