# D51 — E-qaimə в оплате — из списка неоплаченных

## Решение
**E-qaimə в оплате — из списка неоплаченных** (сессия 15). В строке банковской операции поле e-qaimə предлагает неоплаченные e-qaimə выбранного контрагента на дату операции (`reporting.invoices.open_invoices`: остаток по номеру, как в отчёте «E-qaimələr» D38; при расходе — долг контрагенту, при приходе — долг контрагента; таможенные декларации не предлагаются; только проведённые документы), от старой к новой: номер · дата · остаток. Выбор подставляет номер и, если сумма пуста, остаток. Свой номер можно ввести (аванс, e-qaimə ещё не загружена). **Один платёж — несколько e-qaimə:** пункт «Bir neçə e-qaimə…» — окно с отметками (как задачи в Things: Space), введённая сумма платежа распределяется с самой старой (`application.bank.allocate`: каждая полностью, последняя частично), переплата — строка без e-qaimə (аванс); каждая e-qaimə — своя строка на том же счёте и субконто. Учёт оплат по срокам (aging) — позже, отдельно.
