# D149 — Правила учёта держит и сам файл: деньги только целые, закрытый период неизменен
Статус: принято
Дата: 2026-10-26

## Контекст
—

## Решение
**Правила учёта держит и сам файл: деньги только целые, закрытый период неизменен** (ветка `claude/schema-safety`, миграция 0053; аудит схемы, пп. 1–3; пользователь: «структура — по лучшим практикам», «сам продолжай»). SQLite хранил 12.5 и текст в INTEGER, закрытый период держал только код — проверено. Триггеры: (1) INTEGER-колонка — целое или NULL (`<таблица>_integers_*`; при правке — только изменённое; новые таблицы требует `test_integrity_guards`); (2) документ GL и складской в закрытом периоде не проводится, проведённый — не меняется (как `require_open`); (3) источники проведённого документа закрытого периода (банк, конвертация, начисления) не меняются, кроме того, что не делает проводок (референс выписки, второй документ конвертации). Код отказывает раньше словами пользователя (`Ledger.require_changeable`). Цена — ~8 % на записи года разом; STRICT не взят — пересборка всех таблиц у пользователей.

## Последствия
Код: `test_integrity_guards`.
