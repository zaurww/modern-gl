# D119 — Покупка «ждёт e-qaimə» — товар пришёл раньше документов
Статус: принято
Дата: 2026-10-23

## Контекст
—

## Решение
**Покупка «ждёт e-qaimə» — товар пришёл раньше документов** (сессия 45; пользователь: «пришёл товар, документов нет, налоговые приходят через 2–3 дня»). В покупке основание «Ждёт e-qaimə» (рядом с e-qaimə / декларацией): проводится сразу по цене поставщика, без номера (`inventory_documents.awaits_invoice`, миграция 0043; `CHECK`: только покупка без номера). В «Покупках» — «ждёт e-qaimə» жёлтым, в «Bu gün» — «Покупки ждут e-qaimə, с <дата старейшей>». Импорт с портала предлагает e-qaimə поставщика его ждущим покупкам открытого периода: сама выбирает самую раннюю с той же суммой без ƏDV, другие суммы только предлагает (выбор в «Станет»). E-qaimə в покупку (`Inventory.attach_invoice`): номер; при равной сумме — и ƏDV e-qaimə, разложенный по строкам пропорционально сумме (наибольший остаток); проведённая перепроводится на месте (D32). Номер, вписанный руками, тоже снимает метку. `application/inventory/awaiting.py`, `eqaime_import/planning.py`.
