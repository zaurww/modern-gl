## Решение
**Боковая панель — разделы по назначению** (сессия 18, вопрос пользователя: «E-qaimələr — часть отчётности»). Верхний блок больше не общий список: ввод (Журнал, Начальные остатки) — без заголовка; «Отчёты» (Hesabatlar) — ОСВ, E-qaimələr; «Списки» (Siyahılar; как Lists в QuickBooks) — План счетов, Справочники, Шаблоны, Валюты; дальше «Модули» и «Открытые». Раздел — данные `SECTIONS` в `main_window.py`; горячие клавиши не менялись. Карточка, ОСВ по субконто и анализ счёта по-прежнему открываются из ОСВ, отдельными местами не стали.
