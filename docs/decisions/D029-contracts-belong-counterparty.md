# D29 — Договоры принадлежат контрагентам
Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**Договоры принадлежат контрагентам** (1С «подчинённый справочник», миграция 0009): у справочника может быть справочник-владелец, у элемента — владелец. Договор контрагента предлагается и принимается только рядом с ним; договор без владельца — общий. При проведении договор чужого контрагента — ошибка. Старые договоры, использованные ровно с одним контрагентом, получили его как владельца.
