# D220 — Расход партии называет покупку товара, к которой относится
Статус: принято (развивает D211, D219)
Дата: 2026-11-25

## Контекст
Расходы партии отмечались в «Ждущих расходах» сами, только если номер декларации стоял в тексте
услуги. Пользователь: брокеры пишут номер «не всегда, но мы иногда сами определяем». В живых
книгах e-qaimə терминала приходит через месяц одна на несколько деклараций.

## Решение
- У строки покупки «Əlavə xərc» — необязательная колонка «К покупке» («Aid olduğu alış»): покупка
  товара из списка (декларация или e-qaimə, день, поставщик). В ячейке — номер декларации.
- Ссылка — на документ покупки, а не на номер текстом: работает и для местной покупки без
  декларации. Одна строка — одна покупка; e-qaimə на несколько деклараций делится «Разделить
  строку» (F8), каждая часть получает свою; одна строка на несколько покупок поровну отвергнута.
- Ссылка — пометка, не источник проводок: расход ждёт на 15, как раньше, и входит в стоимость,
  только когда его возьмёт «Расходы по партии». Там после выбора покупок сказанное о них
  отмечено само; совпадение номера в тексте работает по-прежнему.
- Покупку товара можно удалить: её расходы остаются ждать без покупки.
