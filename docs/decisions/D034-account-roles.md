# D34 — Счета автоматических проводок — «роли счетов» компании, не коды
Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**Счета автоматических проводок — «роли счетов» компании, не коды** (миграция 0010, таблица `account_roles`; первая роль `input_vat` — НДС к возмещению). Пользователь выбирает любой счёт в «Настройках склада»; шаблон плана задаёт значение по умолчанию колонкой `role` (classic: 19, 1c77: 19.3), миграция — для старых компаний. Поступление: сумма строки без НДС, НДС строки — отдельно (считается по ставке документа 18% / без НДС, правится вручную); проводка Дт счёт роли [субконто поставщика по виду] / Кт счёт расчётов — одна на поставщика. В себестоимость НДС не входит. Без указанного счёта документ с НДС не проводится. Будущие роли (выручка, себестоимость, курсовые разницы…) — так же.
