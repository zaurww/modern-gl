# D231 — Один контрагент не вводится дважды: имя сравнивается без İ/I, кавычек и формы
Статус: принято (уточняет D205, D49)
Дата: 2026-11-27

## Контекст
ELV Battery: «AUTOUNİVERSAL MMC» (VÖEN, из e-qaimə) и «AUTOUNIVERSAL MMC» (без VÖEN) — два
элемента. Выписка Yapı Kredi (D230) VÖEN не даёт; отправитель без VÖEN искался по имени
только среди контрагентов без VÖEN, форма предложила «Добавить в справочник…».
Пользователь: «как быть в будущем, когда это будут вбивать работники».

## Решение
- Имя сравнивается «плоским» (`plain_name`): форма сокращена (MMC = MƏHDUD MƏSULİYYƏTLİ
  CƏMİYYƏTİ), без кавычек, регистра, лишних пробелов, İ/ı; по названию и официальному имени.
- **Выписка:** отправитель без VÖEN — после точного имени и «как в прошлый раз» —
  единственный контрагент с таким именем, какой бы VÖEN у него ни был. Двое — не угадывается.
- **Ручной ввод** (окно элемента, «+ Добавить «…»», ячейка, строка банка): имя, которое уже
  есть, не добавляется — берётся существующий, плашка «уже есть в справочнике — взят он»;
  у существующего без VÖEN введённый VÖEN записывается. Разные VÖEN — два контрагента.
- Импорт e-qaimə не меняется: там ключ — VÖEN.
