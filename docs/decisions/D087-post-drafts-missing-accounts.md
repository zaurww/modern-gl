# D87 — «Провести черновики» спрашивает, куда идут строки без счёта

## Решение
**«Провести черновики» спрашивает, куда идут строки без счёта** (сессия 36; пользователь: «при выборе нескольких фактур для проведения должно появиться окно, чтобы выбрать, на какой счёт они пойдут, и потом нажать Enter; запомнить для контрагента — по желанию»; уточняет D73, D76). Вместо вопроса «Провести?» — окно: в «Alış» — счёт затрат (без складских, D58) и его субконто, в «Satış» — аналитика продажи (D61), если счета продажи её требуют. Выбор идёт во все «открытые» строки пачки (покупка: без товара и без счёта; продажа: без своих субконто); строки с указанным счётом не меняются. Если в прошлый раз все открытые строки ушли в одно место, оно уже подставлено и курсор стоит на «Провести» — повторить месяц = один Enter; пусто — каждой строке как в прошлый раз (D76; для продаж — `remembered_sale_subconto`). Enter в поле только берёт значение и ведёт к следующему, проводит — только на «Провести»; пустое обязательное субконто счёта — сообщение в окне. **Запоминание — без новой таблицы и галочки:** проведённая строка и есть память («как в прошлый раз», D76), отдельное правило «контрагент → счёт» было бы вторым источником правды. Код — `trade_batch` (`open_lines`, `Booking`), `Inventory.fill_sale_subconto`, окно `desktop/batch_post_dialog.py`; тесты — `tests/test_trade_batch.py`.
