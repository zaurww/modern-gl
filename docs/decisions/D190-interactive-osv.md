# D190 — ОСВ по месту: развороты, сортировка, одна колонка, точность, сохранённые виды
Статус: принято
Дата: 2026-10-30

## Контекст
Надстройка пользователя «Интерактивная ОСВ v2.50» (Барышников, 1С 7.7, `OSV2.ert`): «очень
удобные функции, хочу применить эти функции в программе». Функции восстановлены по форме,
макетам и справке (модуль зашифрован); выбраны все четыре.

## Решение
- **Развороты по месту:** строка счёта и любая строка под ним раскрывается по субконто
  (по позициям), корсчетам (только обороты) или месяцам (сальдо переносится); шаги
  вложенные: контрагент → договор → корсчёт. → следующий вид, Shift+→ выбор, ← свернуть,
  Ctrl+→ / Ctrl+← все; то же в правом щелчке. Вид «Субконто» — то же дерево; двойной щелчок —
  карточка (по месяцу — за месяц). Одинаковые узлы — одним запросом (`expand_many`).
- **Сортировка** щелчком по подписи: вверх, вниз, как в плане; соседи каждого уровня.
- **«⋯»:** «Одной колонкой» (кредит в скобках), «С копейками / В тысячах / В миллионах»
  (`ReportModel.scale`; Excel — полные суммы).
- **Сохранённые виды** — под именем в файле компании (`report_views`, 0061: вид называет
  её счета и элементы); в просмотре — только выбор.
- Не взято: отбор по счетам, разделители учёта, печать сразу, контроль итогов.
