# D69 — ƏDV депозит в форме оплаты — две операции из одной формы
Статус: принято
Дата: 2026-10-21

## Контекст
—

## Решение
**ƏDV депозит в форме оплаты — две операции из одной формы** (сессия 19, в ветке — D65; пользователь: «считай, что это отдельный банковский счёт», части обычно в один день, «но всякое бывает»; импорт с портала — позже). В новой операции поставщику / от покупателя на текущем счёте, если в компании есть счёт типа `vat_deposit` и строка одна: «Из банка» + «С депозита ƏDV» («В банк» / «На депозит ƏDV»), под ними депозитный счёт и своя дата (следует за датой операции, пока её не изменили). Выбор e-qaimə делит остаток: ƏDV, ещё не оплаченный с депозита (`OpenInvoice.vat` = ƏDV e-qaimə − оплаты с/на счёт `vat_deposit` по номеру, не больше остатка), — на депозит, остальное — из банка; на самом депозитном счёте — только ƏDV. «Провести» сохраняет две операции, каждая на своём счёте, с той же e-qaimə и строкой — обе или ни одной (`Ledger.save_bank_payment`). Депозит позже — поле пустым, потом операция на депозите с той же e-qaimə. Под суммами — проверка «банк + депозит = итого · e-qaimə оплачивается полностью / останется / больше остатка». Существующая операция правится по одной.
