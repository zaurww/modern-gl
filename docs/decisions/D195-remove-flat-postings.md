# D195 — «Проводки для Excel» убран; отчёты — окна с фильтрами по модулям
Статус: принято
Дата: 2026-11-04

## Контекст
Пользователь о D193: «бесполезен». Имелось в виду другое — как в Logo ERP: у отчёта
своё окно с множеством фильтров и группировок, из которого получается удобный Excel.
Плоская выгрузка всех проводок этого не даёт.

## Решение
Отчёт «Проводки для Excel» удалён вместе с кодом (`reporting/flat_postings`,
`flat_excel`, страница, переводы, тест). Остаётся общее в `infrastructure/report_file.py`
(даты датами, числа числами, несколько листов, таблица Excel) и `export.save_tables` —
основа для будущих отчётов.

Направление, не начато: один общий механизм отбора и группировок; у каждого модуля
(книга, склад, банк) свои готовые отчёты на нём; фильтры — панель справа; Excel «как на
экране» (итоги, уровни) или плоско; сохранённые варианты. Строить — после того как
пользователь назовёт 3–5 реальных отчётов.

## Последствия
D193 — «заменено». Каталог «Все отчёты» и Ctrl+K отчёт больше не показывают; звёздочка,
если стояла, просто пропадает.
