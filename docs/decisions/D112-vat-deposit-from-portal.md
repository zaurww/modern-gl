## Решение
**ƏDV DH — с портала, не из Excel** (сессия 41; пользователь: «его можно автоматически загружать с портала; если открыт — ок, если нет — открыть»; уточняет Э5 из D78). Банк → счёт типа `vat_deposit` → «⋯ → Загрузить с портала…», с даты (по умолчанию — последний день выписок) по сегодня. Вход: живой токен портала в памяти программы (`portal_login.portal_token`), иначе окно портала. API: `vatacc/…/accountInfo` (остаток) и `operation/find.outbox` (операции, по 50); в нём есть ƏDV каждой e-qaimə, в Excel — нет. Дубли: референс = 16-значный номер, у «nb» — id портала; введённое вручную (D69) — тот же день, сумма, направление → только референс. Счёт строки — как в прошлый раз, иначе 60/62, бюджет — роль `output_vat`; новый контрагент — по VÖEN с коротким именем. Проводится всё, что можно, остальное — черновик. Остаток дня — назад от остатка портала. Фирма токена сверяется с VÖEN компании (D113). `application/bank/deposit_import.py`, `ledger/bank_deposit.py`, `desktop/bank_page/portal.py`.

## Последствия
Код: `vatacc/…/accountInfo`, `operation/find.outbox`, `application/bank/deposit_import.py`, `ledger/bank_deposit.py`, `desktop/bank_page/portal.py`.
