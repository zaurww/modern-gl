# D7 — Слой ≠ книга
Статус: принято
Дата: 2026-10-19

## Контекст
—

## Решение
**Слой ≠ книга**: документ лежит ровно в одном слое (`common`, `ifrs_adj`, `tax_adj`), книга = список слоёв. Таблица `books` появится, когда понадобится настройка; пока книги — константы в `reporting`.
