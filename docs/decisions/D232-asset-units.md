# D232 — Строка e-qaimə из N одинаковых объектов: партией или по одной штуке — выбор у строки
Статус: принято (опирается на D136, D173, D194, D199)
Дата: 2026-11-27

## Контекст
Пользователь: «по e-qaimə купили 3 одинаковых основных средства… эти 3 объекта попадают как
один?»; «в qaimə это указано одной строкой»; «клиенты и кейсы бывают разные, кому-то нужен
поштучный учёт. Например сеть ресторанов, 20 кофейных аппаратов в разных точках». Одна строка
с количеством давала один объект с количеством N (D199); поштучно — только F8 N−1 раз.

## Решение
- **По умолчанию — партия:** строка = один объект с количеством N (стулья, одинаковые
  ноутбуки). Ничего не менялось.
- **Поштучно — одним действием:** F8 на строке объектов (счёт со справочником объектов, D194)
  с целым количеством ≥ 2 предлагает «По одной штуке — N строк»: строка становится N
  строками по одной штуке с именами «название №1…№N»; сумма, ƏDV и валюта — поровну, остаток
  копеек — в последней; затем сразу окно «Объекты по названиям строк» (D173). Объект,
  выбранный для партии, остаётся у первой строки. Не больше 200 за раз.
- Отвергнуто: одна строка документа с N проводками — нужна таблица «штуки строки», а строки
  по одной уже дают каждой свою точку (субконто строки) и правятся как обычные.
