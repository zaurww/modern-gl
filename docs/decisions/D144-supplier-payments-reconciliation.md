## Решение
**Сверка оплат поставщикам с e-qaimə — как у покупателей (D143); предупреждение — ƏDV оплаченной e-qaimə не зачтён** (ветка `claude/vat-payments`; пользователь: «сверка так же нужна для закупок»). Отчёт «Оплаты поставщикам и e-qaimə» (`reporting/vat_payments.py`) на общих частях `vat_receipts`: деньги поставщику по номеру и без (`party_money` — те же проводки, что у покупателей, в обратную сторону), раскладка аванса по старшинству, на конец — аванс и неоплаченное; за период — зачтено ƏDV по D138 (итог = «ƏDV к зачёту»). Зачёт идёт по номеру, поэтому e-qaimə, оплаченная (по раскладке), но с ƏDV оплаченной доли больше зачтённого, — предупреждение с суммой: «оплачено без номера — укажите номер в банке», если стоимость по номеру (в т. ч. зачётом аванса) оплачена меньше, иначе «ƏDV не перечислен на депозит». У предупреждений продаж тоже появилась сумма.
