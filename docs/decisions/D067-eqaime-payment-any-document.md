# D67 — E-qaimə в оплате — не только из проведённых документов
Статус: принято
Дата: 2026-10-21

## Контекст
—

## Решение
**E-qaimə в оплате — не только из проведённых документов** (сессия 19, жалоба пользователя: «в модуле банк не показываются номера e-qaimə, поднимал несколько раз»; уточняет D51; в ветке — D63). Список неоплаченных берёт номер сначала из проведённых документов (как было), иначе из черновика — журнала, покупки или продажи (импорт с портала создаёт черновики, D45) — с пометкой «qaralama», иначе из снимка портала (`eqaime_portal`, D53; статусы оборота и «Təsdiq gözləyir») по VÖEN контрагента — с пометкой «portaldan». Из суммы вычитаются проведённые оплаты по номеру. Контрагент узнаётся и по VÖEN: второй элемент справочника с тем же VÖEN — та же фирма. Номер, который знает книга, из черновика и портала не берётся. Номер, известный как покупка (документ «Alış» или входящая на портале), не предлагается при приходе, продажа — при оплате: аванс по непроведённой покупке не выглядит долгом поставщика перед нами (возврат — номер вводится вручную).
