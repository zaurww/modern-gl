# D17 — Вид счёта (A / P / AP) убран
Статус: принято
Дата: 2026-10-19

## Контекст
—

## Решение
**Вид счёта (A / P / AP) убран.** Нормальная сторона сальдо выводится из класса (актив, расход — дебет; обязательство, капитал, доход — кредит; контрсчёт — наоборот). Вместо «AP» — флаг `two_sided` (сальдо бывает с обеих сторон, развёрнуто по субконто, не проверяется). ОСВ подсвечивает красным сальдо не на своей стороне. Колонка `kind` в CSV по-прежнему понимается при импорте.
