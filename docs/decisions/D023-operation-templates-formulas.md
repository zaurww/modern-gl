# D23 — Шаблоны операций: одна сумма S + формулы строк
Статус: принято
Дата: 2026-10-19

## Контекст
—

## Решение
**Шаблоны операций: одна сумма S + формулы строк** (выбор пользователя). Формула: S, L1…Ln, числа, + − * / ( ); точная арифметика, округление итога строки до копеек половиной от нуля. Создание — из документа («Şablon et») и в разделе «Şablonlar»; готовый набор для плана «classic». Шаблон — не учётные данные: меняется и удаляется свободно, с записью в журнал действий.
