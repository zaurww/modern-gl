# D152 — Язык документов — настройка компании, а не интерфейса

Дата: 2026-10-27

—

## Решение
**Язык документов — настройка компании, а не интерфейса** (ветка `claude/document-language`, миграция 0054; пользователь выбрал вариант 1 из двух: «язык документов — настройка компании» или «не сравнивать тексты»). Тексты, которые программа сама пишет в документы («Bank komissiyası», «Konvertasiya AZN → EUR», ƏDV, начисления, переоценка, назначение платежа по умолчанию, элемент «Комиссия банка» по имени), брались из языка интерфейса: после смены языка перестроение и пересчёт склада считали 972 документа демо-года изменёнными и перепроводили их с копией в журнал. Теперь — `i18n.trd`, язык `companies.document_language`: новая компания — азербайджанский, меняется в меню компании «Язык документов» (только для новых документов, в журнал); файл старой программы — язык его записанных текстов (каких больше), один раз; просмотр ничего не пишет. Ставится при открытии (`Workspace.open/view`: окно, API, AI).
