# D46 — «Alış» и «Satış» — два отдельных раздела
Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**«Alış» и «Satış» — два отдельных раздела** (сессия 13; заменяет общий раздел и фильтр из D44). Покупки и продажи — разные потоки: поставщики и входящие e-qaimə против покупателей и исходящих, счета затрат против выручки; общий список с фильтром был по сути вкладками. В блоке «Модули» — «Alış» (Ctrl+0), «Satış» (Ctrl+-), «Anbar». Страница одна (`TradePage(session, doc_type)`): поиск, колонка «Malsatan» / «Alıcı», «+ Alış» / «+ Satış», итог проведённых, «Portaldan e-qaimələr…» грузит только своё направление (inbox / outbox). Модель данных не менялась: документы те же складские (`receipt`, `sale`); остальное из D44 в силе.
