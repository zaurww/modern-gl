# D175 — «Проверка книги»: программа сверяет свои данные, как Verify Data в QuickBooks
Статус: принято (опирается на D101, D149, D155)
Дата: 2026-10-27

## Контекст
База отказывает в неверной строке (D149, D155), но расхождение между таблицами одной
строкой не увидеть. Зрелые системы сверяют себя сами: QuickBooks — Verify/Rebuild Data,
SAP — книгу с подкнигами (FAGLF03) и склад со счетами (MB5L).

## Решение
- Меню компании → «Проверка книги…», только чтение, на копии в памяти (работает и при
  просмотре, D80): файл цел; проведённые документы проходят правила проведения (тем же
  кодом; закрытый с тех пор счёт — не ошибка); сторно зеркально документу; проводки
  модулей открытого периода — те, что дают их документы (перестроение D101 с откатом);
  склад сходится со счетами запасов.
- Исправить программа может одно — «Перестроить проводки» (синяя кнопка, журнал действий;
  при просмотре её нет). Список проверок явный: новый модуль добавляет свою.

## Последствия
`application/verification/`, `inventory/verification.py`, `desktop/verification_dialog.py`;
тесты — `test_verification*.py`. Перестроение склада ускорено в 10 раз (иначе проверка
демо-года — 11 с). Остаток склада по книге — в двух местах («Долг»).
