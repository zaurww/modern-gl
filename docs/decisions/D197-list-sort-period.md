# D197 — Списки «Alış»/«Satış» и склада: сортировка по заголовку; период у покупок и продаж
Статус: принято
Дата: 2026-11-04

## Контекст
Пользователь о списке «Alış»: «стоит делать фильтрацию или сортировку?.. например я хочу
выбрать только qaralama» — «делаем». Список показывал последние 500 документов без периода,
порядок — только по дате.

## Решение
- Щелчок по заголовку списка: по возрастанию, по убыванию, снова исходный порядок (как ОСВ,
  D190); стрелка — в тексте заголовка («Cəmi ↓»). Дата — по дню и номеру, текст — без
  регистра и İ/ş. Порядок держится при перечитывании. «Alış», «Satış», документы «Anbar».
- «Alış»/«Satış» — капсула периода (D105), по умолчанию год рабочей даты: черновики
  прошлых месяцев не теряются из виду; в периоде — все документы, без предела 500.
- Поиск ищет и статус: «qaralama» / «черновик» оставляет черновики.
- Журнал не сортируется: он читается страницами по году (D24), порядок — чтения.
  Фильтров по колонкам, как в Excel, нет.
