# D146 — Выписка банка из файла — шаблон на банк (первым Kapital Bank); проводится только уверенное, остальное — черновик с причиной
Статус: принято
Дата: 2026-10-26

—

## Решение
**Выписка банка из файла — шаблон на банк (первым Kapital Bank); проводится только уверенное, остальное — черновик с причиной** (ветка `claude/bank-import`; пользователь: «для разных банков формы разные… будем добавлять шаблоны»; «неправильно e-qaimə или ничего не написал — в любом случае нужен review»; уточняет «Импорт» D78). Шаблон — модуль в `application/bank/files/` → общий `BankFile`; файл сверяется по своим остаткам. «Банк → ⋯ → Загрузить выписку из файла…», несколько файлов, счёт по IBAN (выбранный запоминает IBAN); просмотр с галочками, на проверку — вверху; остатки дней — в выписки; повтор без дублей (референс строки). Сразу проводятся: комиссия, перевод, зарплата, налог с кодом бюджета, уже проведённым раньше, оплата по найденным неоплаченным e-qaimə (MT, AA) в пределах долга. Черновик: новый контрагент, номер не найден или нет, сумма больше долга, налог впервые, непонятное. Строки двух своих счетов в разной валюте — одна «Конвертация» с комиссией (одна сторона — черновик до второго файла): банк пишет документ модуля конвертации.

## Последствия
