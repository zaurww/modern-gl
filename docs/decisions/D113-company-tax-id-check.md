# D113 — VÖEN компании — сверка с порталом перед любой загрузкой
Статус: принято
Дата: 2026-10-23

## Контекст
—

## Решение
**VÖEN компании — сверка с порталом перед любой загрузкой** (сессия 41; пользователь: «случайно можно скачать данные другой компании, потом придётся долго чистить»). `companies.tax_id` (миграция 0040, 10 цифр или пусто); при создании компании — необязательный вопрос, правка — меню компании → «VÖEN компании…». Всё с портала (e-qaimə, сверка, ƏDV DH) берёт токен через `desktop/portal_company.company_token`: VÖEN известен — берётся только токен этой фирмы, окно входа ждёт, пока на портале выбрана она; чужой — «ничего не загружено», без обхода. VÖEN не задан — первый вход спрашивает «Это компания …?» и запоминает VÖEN портала (вводить руками не нужно). Токен портала — один на программу, только в памяти (`portal_login.portal_token`).

## Последствия
Код: `desktop/portal_company.company_token`.
