# D-new — Файл банка не создаёт контрагентов: имя — с портала, строка ждёт с VÖEN и именем
Статус: принято (уточняет D146, D184)
Дата: 2026-11-06

## Контекст
Пользователь: «правильный вариант для имени контрагентов, это e-qaimə c порталов», «я на
стороне надежности». Было: выписка добавляла контрагента с именем банка как официальным;
строка без VÖEN давала второй элемент рядом с e-qaimə. SAP: банк справочник не ведёт.

## Решение
- Отправитель ищется по VÖEN, без него — по точному имени, затем «как в прошлый раз».
- Не найден — черновик без контрагента с причиной; VÖEN и имя банка хранятся в операции
  (`party_tin`, `party_name`, миграция 0065) как подсказка.
- Контрагент появился — черновики находят его сами (`adopt_parties`): после импорта e-qaimə,
  при следующей выписке, кнопкой в форме; раскладка как при импорте, остаётся черновиком.
  Сохранённое человеком не трогается.
- Форма: плашка «В выписке: …» и кнопка «Добавить в справочник…» или «Подставить».
- ƏDV DH не меняется: её имена — с портала.

## Последствия
`application/bank/parties.py`, `party_commands.py`; тесты — `test_bank_parties.py`. Выписка
в пустую компанию даёт больше черновиков: сначала e-qaimə, потом банк.
