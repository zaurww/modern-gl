# D73 — Статус документа — не похож на чекбокс; черновики покупок и продаж проводятся разом
Статус: принято
Дата: 2026-10-22

—

## Решение
**Статус документа — не похож на чекбокс; черновики покупок и продаж проводятся разом** (сессия 22, пользователь: «пустой кружочек путают с чекбоксом и кликают»; «от SOCAR каждый месяц фактуры — знаю, что это топливо, хочу провести все разом»). В списках и в шапке документа: проведён — синяя галочка без круга, черновик — маленькая янтарная точка (`icons.status_mark`); круг Things остался только там, где строку действительно отмечают (выбор e-qaimə при оплате, `tick_icon`). В «Alış»/«Satış» — кнопка «Провести черновики: N»: выделенные строки (Ctrl/Shift), иначе все черновики списка после поиска; с вопросом-подтверждением. Строка покупки без товара и без счёта получает счёт и субконто последней проведённой покупки этого поставщика (строка с тем же названием, иначе последняя строка расходов); черновики идут по дате, поэтому проведённый раньше учит следующие. Каждый документ — своя транзакция: не проведённый остаётся черновиком, причина показывается списком. Код — `application/trade_batch.py`, `Inventory.fill_expense_account`. Тесты — `tests/test_trade_batch.py`.
