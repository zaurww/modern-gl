# D155 — Файл не принимает несуществующий день, нечитаемое время, флаг не 0/1 и тип счёта чужого класса
Статус: принято
Дата: 2026-10-27

## Контекст
—

## Решение
**Файл не принимает несуществующий день, нечитаемое время, флаг не 0/1 и тип счёта чужого класса** (ветка `claude/schema-checks`, миграция 0057; аудит схемы, пп. 4–6, 9; пользователь: «исправляем?» — «давай»). Триггеры, как в 0053 (при правке — только изменённое): (1) каждая дата — день календаря (GLOB пропускал `2026-02-30`); (2) каждая отметка времени — читаемая `datetime()`; (3) флаги `active`, `is_group`, `contra`, `two_sided` — 0/1, `accounts.currency` — 0/1/2 (D28), базовая валюта — код; (4) класс счёта — класс его типа (D35): смена класса — одной командой с типом. Дата сверки e-qaimə — день пользователя (`common.local_day`), а не UTC. П. 6 аудита ложный: доли доп. расходов ссылаются на строки своего документа (проверено на 313 долях), каскад — внутри документа. П. 9: тип ↔ класс миграции нарушить не могли (0012 ставила тип при совпадении класса), строка «Требует внимания» не нужна; неверный по смыслу тип (свой 60 не поставщики) правилом не ловится. Пп. 7–8 — к серверу.
