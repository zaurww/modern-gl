## Решение
**ОПиУ по IFRS 18, без ƏDV; отложенный налог — свои типы счетов** (сессия 54; пользователь: «в income statement есть ƏDV… ни в каком P&L такого не видел», «формат P&L поправить по IFRS (operating, investing, finance)», «в плане счетов должен быть deferred tax liability and asset»; «все твои идеи принимаю»). Выручка — без НДС (IFRS 15.47), брутто и ƏDV — только в раскрытии «по счетам» (меняет строку НДС из D102). Категории IFRS 18: операционная, инвестиционная, финансирование, налог; итоги «Операционная прибыль» и «Прибыль до финансирования и налога»; прочие доходы/расходы — по типам (проценты по кредиту — финансирование, курсовые — по источнику); один формат для всех книг; ДДС — проценты по IAS 7 в той же категории. Типы `deferred_tax_asset/liability` (баланс — отдельной строкой, долгосрочные), налог в ОПиУ — текущий и отложенный; 09/77 в шаблон classic, 91.3/91.4 в 1С 7.7; миграция 0048. Курсовая разница — проводка в валюте без суммы в валюте (переоценка) или против 57 (конвертация). Код — `reporting/profit_loss.py`.
