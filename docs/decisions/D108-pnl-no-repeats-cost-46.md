# D108 — ОПиУ без повторов счёта; расход на 46 — себестоимость; Esc не открывает соседнюю страницу
Статус: принято
Дата: 2026-10-23

## Контекст
—

## Решение
**ОПиУ без повторов счёта; расход на 46 — себестоимость; Esc не открывает соседнюю страницу** (сессия 41; «mənfəət zərər странный… почему показываются счета?», «esc везде медленный»). Строка ОПиУ с одним счётом его не повторяет — сама ведёт к карточке (`Line.account_id`), статьи под ней. На счёте продаж всё, кроме покупателя и денег (`BUYER_TYPES`), — себестоимость (перевозка Дт 46 Кт 60). Закрытие страницы не даёт боковой панели открыть соседний пункт (сигналы выключены): Esc 3,5 → 0,09 с. По месяцам строка выделяется целиком (Ctrl+C), выбранная сумма обведена (`Column.cell`).
