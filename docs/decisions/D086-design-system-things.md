## Решение
**Дизайн-система: эволюция Things, «вау» без шума** (сессия 36; пользователь: «самые лучшие практики мирового дизайна… чтобы пользователи наслаждались»; согласован кликабельный макет — артефакт «Modern GL — макет дизайна»). Направление — не новый стиль, а единая система поверх нынешней темы. **Шапка страницы одна на всех:** крупный заголовок · серая подпись · поиск · **одна** синяя кнопка главного действия («Yeni sənəd», «+ Alış»…) · «⋯» для остального; круглая «+» в углу (FAB) и ряды ссылок в шапке убираются. **Контраст:** заголовки блоков — основной цвет текста, жирные, крупнее (мелкие серые прописные сливаются с фоном); серый — только для пояснений, дат, номеров. **Тише — сделанное, громче — ждущее:** проведённые строки чуть серее основного текста, черновик — обычный цвет и янтарная точка; **курсива нет нигде**. **Иконки** боковой панели — один набор контурных (Lucide), серые; цвет — у выбранного пункта (акцент) и у «Bu gün». Шрифт Inter с цифрами одной ширины (суммы стоят столбиком). «Açıq» — не больше нескольких последних + «Hamısı (N)…». **Живость:** короткие переходы (≤ 200 мс, без них при «уменьшить движение»), уведомление-«тост» внизу с «Geri al» вместо строки состояния, галочка проведения «рисуется». **Главная «Bu gün» — тихая** (первый вариант с карточками, плашками и «последними документами» пользователь назвал шумным): одна узкая колонка, три списка с тонкими линиями — «Diqqət tələb edir» (черновики → «Hamısını keçir», сверка с банком, неоплаченные e-qaimə, отрицательный остаток), «Pul» (кассы и банки: название · счёт, сумма справа) и «Məzənnələr» (курсы USD/EUR на сегодня, не загружен — «Yüklə»); без цветных иконок, цвет — только у отрицательной суммы; строки модулей добавляют сами модули. **Ctrl+K** — одно окно поиска и команд: команды, отчёты, счета, контрагенты, документы; поиск через `fold` (ş = s, ə = e). Тёмная тема — по системе или выбором.
