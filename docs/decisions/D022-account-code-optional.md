## Решение
**Код счёта необязателен.** Счёт без кода известен по названию; коды, если заданы, уникальны. Внутри программы счёт — это id (интерфейс, отчёты, ключи открытых страниц); код — только подпись. Среди соседей сначала счета с кодом (по коду), потом без кода (по алфавиту). Миграции идут с выключенными внешними ключами и проверкой `foreign_key_check` перед фиксацией (нужно для пересборки таблиц).
