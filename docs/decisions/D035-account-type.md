## Решение
**Тип счёта — смысл счёта при любом коде** (как `account_type` в ERPNext, Account Type в QuickBooks/Zoho; уточняет D14). Фиксированный список программы, 30 типов (с сессии 11 — «Переводы в пути», `transit`, миграция 0019; «ƏDV depozit hesabı», `vat_deposit`, миграция 0021, D41) (`domain/accounts.py`: касса, банк, покупатели, поставщики, ƏDV к возмещению, запасы, ОС, выручка, себестоимость, финрезультат…); класс выводится из типа, контрсчёт остаётся отдельным флагом. Тип необязателен: допустим класс без типа. Субсчёт наследует тип родителя того же класса; смена типа группы переносится на субсчета с тем же типом; смена класса стирает тип другого класса. Типы шаблонов — в `templates/chart_<name>_types.csv` (не зависят от языка); старые файлы размечены миграцией 0012 по кодам шаблонов. Роль счёта (D34) без выбранного счёта берёт единственный активный счёт нужного типа (сделано). Дальше (не сделано): формы отчётов сопоставляют строки с типами, отдельные счета — вручную (D31); копирование плана из другой компании; шаблон национального плана АР. Цель — консультант с разными планами у клиентов получает одинаковые отчёты и автоматику.
