# D211 — Расходы партии берутся галочкой из того, что ждёт в книгах
Статус: принято (развивает D85)
Дата: 2026-11-06

## Контекст
Услуги брокера и перевозчика приходят e-qaimə на счёт 15. «Из проводки» проводки склада не брало,
поэтому их вводили в партию заново: Кт 60 второй раз, долг задваивался (партия №33, черновик №39).
Пользователь: «всё путано, тем более для нового человека».

## Решение
- Партия берёт **строку услуги покупки**, а не её проводку (`landed_cost_charge_lines`, 0066):
  покупку можно перепровести, строка остаётся. Проводка: Дт 41 Кт счёт услуги; долг не меняется.
- «+ Ждущие расходы…» вместо «+ Из проводки…»: услуги покупок и проводки журнала, остаток каждой.
  Ждут — счета типа `inventory` без справочников (15), не по коду; «Все расходы» — остальные.
  После выбора покупок окно открывается само, расходы с номером её декларации отмечены.
- Партия не раньше услуги: она переносит то, что уже на счёте, и проводятся они в этом порядке.
- Расход, введённый с суммой ждущего, при проведении ловится вопросом. Сравнение по сумме: имена
  одного перевозчика разные.
- «Bu gün» показывает услуги, ждущие партии: пока они ни в чьей себестоимости.
