Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**Импорт e-qaimə с портала — внутри программы, только черновиками** (сессия 12). Вход — сам портал `new.e-taxes.gov.az` во встроенном браузере (QtWebEngine), ASAN İmza как обычно; программа берёт токен из `localStorage['aztax-jwt']`, когда в нём есть VÖEN выбранной компании (как etaxes-ext, `lib/auth.js`); профиль браузера хранится в данных программы. API — как в etaxes-ext: `find.inbox` (покупки) / `find.outbox` (продажи) по одному статусу, страницами по 50, `invoice/{id}` со строками; заголовок `x-authorization`; суммы читаются как Decimal. Берутся только статусы оборота (approved, approvedBySystem, cancelationRefused, correctionRefused). Товар или услуга — по коду строки (`99…` — услуга, иначе товар, как в детальном Excel etaxes-ext). Что станет строкой: то, чем стала строка с тем же названием у того же контрагента в прошлый раз (товар или счёт + субконто), иначе товар с тем же названием, иначе ничего — такая строка покупки не проводится, пока пользователь не выберет товар или счёт. Контрагент — по VÖEN (главный идентификатор; без VÖEN — по точному имени). Новые контрагенты показываются отдельным списком, один на VÖEN: название с портала и предложенное короткое («"ALFA" MƏHDUD MƏSULİYYƏTLİ CƏMİYYƏTİ» → «ALFA MMC»), которое пользователь правит; их можно добавить отдельно, без документов («Kontragentləri əlavə et»). Имя существующего контрагента импорт сам не меняет. Официальное имя с портала хранится отдельно (`subconto_values.legal_name`, миграция 0024): у известного контрагента без него — запоминается молча; если по тому же VÖEN пришло другое (без учёта регистра, кавычек и пробелов) — блок «Adı dəyişib»: было / стало на портале, имя в программе и новое (предложено короткое); отмеченные переименовываются, у всех запоминается новое официальное имя, больше не спрашивается. История не теряется: проводки ссылаются на контрагента, не на имя. Договор не подставляется. Документ с тем же номером e-qaimə повторно не создаётся; возвраты и отрицательные суммы не импортируются. Всё — черновики: поставщики ошибаются в названиях и кодах, каждый документ проверяется глазами. Фирма, под которой вошли на портал, показана в окне (у компании в программе VÖEN пока нет).
