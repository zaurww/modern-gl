## Решение
**«Передача дел…» — вся компания текстом в zip** (сессия 30; развивает D79, упрощённый вариант: один журнал за всё время, без разбивки по годам). Меню компании → «Передача дел…» → файл `<компания> — передача дел <дата>.zip`, без других вопросов. Внутри папка: `README.txt` (компания, число документов, период, что в каких файлах, как читать, команды hledger), `<книга>.journal` (D79) и `osv-<книга>.txt` — ОСВ с начала года по дату (книги МСФО и налог — только если включены параллельные книги), `directories.csv` (все справочники: вид, код, название, юр. название, VÖEN, страна, валюта; `;` и BOM для Excel), `rates.journal` (курсы — директивы `P`, если есть). Документы с датой позже сегодняшней тоже входят: дата пакета — поздняя из двух. Zip пишется в `.part` и переименовывается целым. Код — `reporting/handover.py` (ядро), тесты — `tests/test_handover.py`. Позже: журнал по годам с входящими остатками, CSV проводок, beancount.

## Последствия
Код: `directories.csv`, `reporting/handover.py`, `tests/test_handover.py`.
