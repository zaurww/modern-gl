# D33 — Landed cost — по образцу ERPNext Landed Cost Voucher, без зашитых номеров счетов
Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**Landed cost — по образцу ERPNext Landed Cost Voucher, без зашитых номеров счетов** (реализовано в сессии 7: НДС в поступлении, «Расходы по партии», валюта в поступлении и расходах, отчёт «Себестоимость партии»; курс фиксируется на документе, по умолчанию — курс дня). Документ «Расходы по партии»: несколько поступлений (партия из нескольких инвойсов, понятие «Partiya»), таблица расходов, способ распределения (количество / стоимость / вручную) с колонкой «на строку». Строка расхода — на выбор пользователя: (а) **уже введённая проводка GL** (фактура брокера, таможни на любом счёте) — документ переносит её сумму на запасы (Дт счёт запасов / Кт счёт из той проводки), остаток нераспределённого учитывается; (б) расход прямо в документе: статья, счёт расчётов + субконто, сумма, ƏDV, валюта и курс. Счета (ƏDV к возмещению и др.) — из настроек склада, по умолчанию из шаблона плана. ƏDV в поступлении: сумма без ƏDV + колонка ƏDV (18% по умолчанию, правится). Отчёт «Себестоимость партии»: цена в валюте, курс, манаты, каждая статья отдельно, итог и цена за единицу.
