# D166 — Настройки пользователя — Preferences
Статус: принято
Дата: 2026-10-27

## Контекст
`QSettings()` создавался напрямую в 29 местах 14 файлов: имя ключа, тип и значение по умолчанию повторялись в каждом.

## Решение
Всё, что программа помнит для пользователя между запусками, — `desktop/preferences.py`: ключ назван один раз, у него тип и значение по умолчанию, чтение и запись — методами `Preferences` (`prefs()` — новый объект над тем же QSettings). Данные компании там не хранятся — они в её файле. `QSettings(` в `src` — только в `preferences.py`.

## Последствия
Код: `desktop/preferences.py`. Тест: `tests/test_preferences.py`.
