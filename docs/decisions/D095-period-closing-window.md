## Решение
**Закрытие периода — окно в меню компании и в Ctrl+K** (сессия 39, критерий готовности №7 «Брошюры требований»; пользователь: «продолжай этапы сам»). `Ledger.set_closed_through` (с аудитом) был только в ядре. Окно «Закрытие периода…» (`desktop/period_dialog.py`; нет при просмотре и в режиме «Только склад»): заголовок — как сейчас («Период закрыт по …» / «Все периоды открыты»), дата «Закрыть по» (по умолчанию — конец месяца перед рабочей датой или уже закрытый день), в одно нажатие — конец прошлого месяца / квартала / года (`application/period.py`, `period_ends`; совпадающие дни — один раз). Предупреждение: черновики книг по эту дату (`drafts_through`) — после закрытия их нельзя провести; более ранняя дата — «Открыть часть периода» с указанием, что откроется; «Открыть все периоды» — с вопросом. После изменения страницы строятся заново (закрытое открывается только для чтения). Черновики склада не считаются: ядро не читает таблицы модулей (D71). Причину при открытии закрытого периода спрашивает D96.
