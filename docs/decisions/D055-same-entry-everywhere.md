## Решение
**Ввод одинаковый во всех формах, как в журнале** (сессия 17, пользователь: «во всех вкладках ввод должен быть идентичен, удобен и быстр как в журнале»). Enter = Tab в шапке любой формы — общий `widgets.enter_goes_on` (журнал, банк, конвертация, складские документы, «Расходы по партии», начальные остатки, редактор шаблонов). Выбор из списка в формах — только `PickBox` (поиск по набору): конвертация, шапка склада (НДС, основание, валюта), способ распределения. Новое имя — пунктом «+ Добавить «…»» в списке: в банке (контрагент, банк, договор — без окна; цифры — это VÖEN, тогда окно справочника), на складе (склад — без вопроса; товар — вопрос «услуга / товар» и окно товара, ему нужны единица и счёт), в «Расходах по партии» и шаблонах (субконто). Отказ («Xeyr») оставляет курсор в ячейке с введённым текстом, «Bəli» — дальше (`postings.edit_next` / `edit_again` для любой таблицы). В конвертации Ins — комиссия, Ctrl+Del — убрать.
