## Решение
**Класс счёта (уровень 1 классификации для отчётности)**: asset / liability / equity / revenue / expense + признак контрсчёта; NULL = не задан. Новый счёт наследует класс родителя, иначе A→asset, P→liability. Смена класса группы переносится на субсчета, которые имели тот же класс.
