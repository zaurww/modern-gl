# D-new — Банк: проверка черновиков выписки — курсор на счёте, налог без угадывания
Статус: принято
Дата: 2026-11-27

## Контекст
Проверка загруженной выписки (Ctrl+Enter — следующий черновик): курсор вставал на сумму, а
правится счёт; налог приходил с 68.1 — первым налоговым, почти всегда неверным; код бюджета без
года («4121211DSMF…») не узнавался; назначение закрывал список счетов.

## Решение
- Открытая операция: курсор — на счёте строки без счёта, иначе первой строки.
- Налог: налоговых счетов несколько — счёт пуст, черновик «выберите счёт» (не на невыясненные,
  D184); один — он. То же в форме при виде «Налоги».
- Код бюджета — 7 цифр в начале назначения, год необязателен.
- Черновик налога без счёта (или с прежним 68.1) при открытии получает счёт последнего
  проведённого с тем же кодом; выбранное руками не меняется; до сохранения не пишется.
- Над строками проверяемой операции — «Назначение: …» целиком.
- «ОСВ по субконто»: остаток элемента не на стороне счёта — красным, как в ОСВ.
