# D177 — Колонки отчёта: порядок и ширина мышью запоминаются
Статус: принято (дополняет D116)
Дата: 2026-10-27

## Контекст
D116 запоминал только выбор колонок; ширина, сдвинутая мышью, пропадала при обновлении,
порядок поменять было нельзя (STATUS «Дальше», п. 3).

## Решение
- Подпись колонки тянется мышью — колонка переезжает; пара Дт/Кт под одной подписью
  едет целиком, первая колонка (названия) остаётся первой. Порядок держит модель отчёта,
  шапка возвращается к своему — подписи пар рисуются как прежде.
- Край подписи тянется — ширина остаётся, узкое окно её не отнимает.
- Всё запоминается на вид отчёта, как выбор колонок (QSettings
  `reports/column_order/<вид>`, `reports/column_widths/<вид>`); колонка, новая в отчёте,
  встаёт на своё место. «Колонки по умолчанию» сбрасывает выбор, порядок и ширины.
- Только страницы отчётов с «Колонки…»; финансовая отчётность (D107) — без этого.
