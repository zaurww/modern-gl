# D212 — Таможенный платёж: один платёж, строки по смыслу
Статус: принято (развивает D211, D85)
Дата: 2026-11-06

## Контекст
Пользователь: платежей обычно два. По qısa idxal bəyannaməsi — только AZƏRTERMİNAL и ƏDV с него;
по основной декларации — ƏDV, сборы, вторая часть терминала, другие сборы. ƏDV банковского платежа
программа не видела: номер декларации на нём не указать.

## Решение
- Банк, «⋯ → Таможенный платёж…»: декларация, сборы, терминал, ƏDV. Одна операция банка, счета не
  выбираются. Сборы — Дт счёт доп. расходов; терминал — Дт 60 с его ƏDV: его начисляет e-qaimə,
  отдельная проводка задвоила бы 19; ƏDV декларации — Дт 19 Кт 60 [таможня], оплата Дт 60 [таможня]
  Кт 51 под номером декларации: так его читает зачёт.
- Строка банка с номером, который в книгах есть как декларация, получает вид `customs` сама.
- «Счёт дополнительных расходов» — роль в настройках склада: с него начинается новая строка расхода
  партии, на нём ждут расходы. Не указан — прежняя догадка по типу и счёт поставщика.

## Последствия
`application/bank/customs_payment.py`, `desktop/bank_page/customs_payment.py`. Начисление ƏDV — свой
документ журнала: удаление платежа его не удаляет. Импортированную строку выписки окно не разбивает.
Два номера груза (короткий и основной) не связаны. Тесты — `tests/test_customs_payment.py`.
