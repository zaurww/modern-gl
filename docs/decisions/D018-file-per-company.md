Статус: принято
Дата: 2026-10-19

## Контекст
—

## Решение
**Отдельный файл на каждую компанию** (`<Название>.gl` в папке «Документы\Modern GL»). Компания — единица передачи другому работнику: передать = отдать файл; «Добавить из файла…» подключает чужой файл, старый общий файл автоматически раскладывается по компаниям. «Удалить компанию» требует ввести название и переносит файл в подпапку «Silinmiş». Внутри файла схема прежняя (`company_id` остаётся — пригодится для серверной версии).
