# D38 — E-qaimə — номер в строке проводки
Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**E-qaimə — номер в строке проводки** (миграция 0015, `postings.invoice`): номер пишется как на портале (без пробелов, заглавными; `domain/invoice.py`), даты нет — дата документа. Колонка «E-qaimə» в форме — после «Содержания» (вставка из Excel по порядку не сдвигается), видна, когда в документе есть строка по расчётному счёту (типы payable, receivable, авансы, other_receivable/liability, или счёт без типа с субконто «Контрагенты») или ƏDV (input_vat, tax_payable). Сторно переносит номер. Быстрая строка: `… 1180 №MT2410001 Содержание`; импорт — колонка «E-qaimə». Отчёт «E-qaimələr» (Ctrl+8, `reporting/invoices.py`): по номеру — Дт/Кт расчётных счетов, ƏDV (строки по ƏDV-счетам), остаток, контрагент/VÖEN/договор, документы; показан, если есть проводка в периоде, суммы — нарастающим итогом на конец; «Только неоплаченные» — все с остатком; один номер у разных контрагентов — красным. Так остаток по каждой e-qaimə получается сам, если оплату помечать тем же номером. **Складское поступление** (миграция 0016): в шапке «Основание» — E-qaimə или «Декларация» (gömrük bəyannaməsi, импорт) — и номер; номер и вид (`invoice_kind`: NULL = e-qaimə, `customs`) идут в проводки поступления (Дт 41 / Кт 60 и Дт 19 / Кт 60); отчёт различает их (колонка «Основание», ключ — вид + номер). Не сделано: дата e-qaimə отдельно от даты документа (обсуждается); номер в «Расходах по партии»; сверка с выгрузкой портала/etax-ext (нужен образец).
