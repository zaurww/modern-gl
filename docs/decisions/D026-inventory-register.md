## Решение
**Склад — отдельный количественно-суммовой регистр, атомарно связанный с GL.** Товары и склады используют общие значения субконто; количество хранится в миллионных долях базовой единицы, сумма — в копейках. Первая оценка — скользящая средневзвешенная, отрицательные остатки запрещены. Landed cost создаёт стоимостные движения без количества и при позднем поступлении делится между остатком и расходами. До появления пересчёта задним числом складские документы проводятся только по порядку дат.
