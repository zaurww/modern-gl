# D173 — Много строк покупки разом: выделенные строки берут одно значение, ОС — по названиям строк
Статус: принято (уточняет D172)
Дата: 2026-10-27

## Контекст
Пользователь попробовал D172 на e-qaimə из 15 строк (5 ОС, 10 МБП): «выбираю в 1-ой строке
01, во всех 15 строк появляется 01. Потом для 1-й строки выбираю имя ос, во всех других
строк появляется это имя… к каждой строке спускаешься и меняешь (добавляешь новое имя)» —
на предложение (субконто не расходится, выделение строк, объекты по названиям) — «давай
попробуем».

## Решение
- Субконто строки больше не расходится по другим строкам (у каждой строки свой объект);
  счёт по-прежнему идёт в строки без счёта (D172).
- Несколько строк выделяются (Shift+↓, Shift/Ctrl с мышью); значение списка — счёт,
  субконто, склад, месяц расхода — выбранное в одной из них, ставится во все выделенные,
  где колонка принимает его (субконто — тот же справочник). «Куда» и имя строки — по одной.
- Справочники, где у каждой строки свой элемент — «Основные средства», «Нематериальные
  активы»: пустая ячейка открывается с названием строки (Enter — новый объект);
  кнопка «Объекты по названиям строк» (видна, пока у такой строки нет объекта) — окно
  «Строки — товары» с отмеченными строками; каждая получает объект по своему названию, имя,
  которое уже есть, — тот же объект; одна транзакция (`Ledger.add_named_values`).

## Последствия
Хранение и проводки не менялись. Код — `inventory_document_page/lines_spread.py`
(`set_on_rows`, `PER_LINE_KINDS`), `line_objects.py`, `lines_table.py` (выделение);
тест — `tests/test_line_objects.py`.
