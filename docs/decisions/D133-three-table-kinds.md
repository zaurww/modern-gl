## Решение
**Три вида таблиц: список, отчёт, ввод** (ветка `claude/table-kinds`; пользователь: «продолжить тему вида таблиц», выбор: списки «во всю ширину», открытие — «двойной, банк — одним»). Было: каждая страница задавала ширины сама, склад обрезал последнюю колонку. Стало: список — `ListTable` во всю ширину, растёт текстовая колонка (`fill`, по умолчанию первое название), остальные по содержимому; отчёт — `ReportTable` (подгонка вынесена из `ReportPage`, план счетов — `ChartTable`), на неё же остатки и движения склада; ввод — существующие таблицы. Двойной щелчок / Enter открывает строку, банк — одним щелчком (D132). Свой `QTableView`/`QTableWidget` вне этих мест — нельзя (`tests/test_table_kinds.py`). Список с галочками или группами остаётся `QTreeWidget`, ширины — `fit_tree` (растут названия и длинные пояснения); сверка e-qaimə — своя: без прокрутки вбок.
