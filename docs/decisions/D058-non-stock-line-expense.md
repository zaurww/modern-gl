# D58 — Строка без товара не идёт на складской счёт; «Расходы по партии» → «Дополнительные расходы»
Статус: принято
Дата: 2026-10-21

## Контекст
—

## Решение
**Строка без товара не идёт на складской счёт; «Расходы по партии» → «Дополнительные расходы»** (сессия 18, вопрос пользователя по e-qaimə: услугу провели на 10 [Avadanlıqlar, ANBAR1], на склад ничего не пришло). Счёт с субконто Товар и Склад («складской») не предлагается в «Счёте затрат» покупки и не проводится там (`Inventory._check_not_stock`, `Catalog.is_stock_account`): иначе ГК показывает товар, которого нет на складе. Товар попадает на склад только через колонку «Товар». Покупка/продажа только услуг — без колонок «Склад» и «Ед.»; второе и третье субконто в заголовке называются видом субконто («Müqavilə»), если у строк он один. Документ landed cost называется «Дополнительные расходы» / «Əlavə xərclər»: учёт не партионный (средняя, D26), «партия» путала.
