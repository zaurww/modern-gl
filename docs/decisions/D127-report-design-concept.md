## Решение
**Дизайн отчётов — один концепт `docs/DESIGN.md`; ОСВ — вариант B; сетка по умолчанию** (сессия 54; пользователь: «написать отдельный концепт, чтобы… все соответствовали друг другу», «в заголовке ОСВ раздельные линии — не очень», «может быть всё-таки бледную серую сетку?», выбор по макету: «B, сетку — настройкой в оформлении, по умолчанию пусть будет сеткой»; уточняет D86 и п. 5 CONCEPT). Подпись группы колонок — без своей линии; без фона под группой (полосу под оборотами пользователь снял: «серый фон… не нужен»); бледная сетка `P.hairline` — «Оформление → Сетка в отчётах» (`reports/grid`, включена); ноль — пустая клетка вместо «–»; сумма в валюте под счётом — свой цвет `P.currency` (серый сливался с субсчетами); остатки склада — таблица отчёта (24 px, сетка). Код — `desktop/reports_page/table.py`; панели — `segments`, `add_to_bar`, без «Formalaşdır» (F5).
