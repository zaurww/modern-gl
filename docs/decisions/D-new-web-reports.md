# D-new-web-reports — Отчёты в браузере: локально и только чтение
Статус: принято (опирается на D24, D77, D80, D83, D90, D111, D122, D179)
Дата: 2026-11-06

## Контекст
Пользователь спросил, можно ли перенести программу в веб, затем: «можно сделать веб
интерфейс?». Из четырёх вариантов (отчёты локально, отчёты через интернет, полный веб с
вводом, только план) выбрал первый: «Отчёты локально».

## Решение
- Пакет `src/modern_gl/web`, верхний слой рядом с `desktop`, `assistant`, `api`. Запуск —
  `uv run modern-gl-web`. Настольная программа остаётся главной, стек не меняется (D179).
- Страницы: ОСВ → карточка счёта → документ, журнал с поиском. Цифры — из
  `reporting.answers`, тех же, что у AI и API; своей логики учёта в `web` нет.
- Только чтение: файл открывается снимком (D80, `assistant.companies.Companies`), сервер
  отвечает только на GET. Компания «только склад» (D90) отчётов по книгам не показывает.
- Только этот компьютер: слушает `127.0.0.1`, отвечает лишь на `Host` с `127.0.0.1` или
  `localhost` (чужой сайт не достучится через своё имя), CSP без внешних источников. Входа
  нет: страницы может открыть любая программа на этом компьютере.
- Без новых зависимостей: `http.server`; все чтения — в одном потоке (соединение SQLite).
- Цвета — копия из `desktop/theme/palette.py` (импорт принёс бы Qt); совпадение проверяет
  `tests/test_web.py`.

## Последствия
- Доступ через интернет, ввод документов, пользователи и PostgreSQL — отдельные решения.
- В консоль печатается только адрес: в cp1251 нет букв «ı», «ə», и сервер падал при старте.
- Длинные списки обрезаны по `answers.LIMIT` (500 строк) со строкой «ещё N не показано»:
  листания нет.
