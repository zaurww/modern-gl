# D-new — Главное окно — композиция частей, а не цепочка наследования
Статус: принято
Дата: 2026-10-27

## Контекст
Окно было одним объектом, нарезанным по файлам наследованием `CompanyFiles ← OpenPages ←
ReportPlaces ← MainWindow` (≈1 470 строк классов); части звали друг друга через 12
«крючков» `raise NotImplementedError`, и любой метод мог тронуть любое поле.

## Решение
`MainWindow(QMainWindow)` держит части полями и связывает их сигналами в `_connect()`
(ветка `claude/audit-window`, аудит интерфейса): `CompanySession` (`company`) — файл
компании, сигналы `opened` / `closing` / `none_left`, что ему нужно от страниц, передаётся
при создании (`confirm_close`, `notify`); `PageStack` (`page_stack`) — открытые страницы,
боковая панель, Esc — назад, чего нет — просит сигналом `place_wanted`; `Navigator`
(`nav`) — что открывается по ключу; его `ReportPlaces` (`reports`) — отчёты. Окну
остаются вид, язык и имя пользователя (то, что открывает компанию заново), меню
компании (`menus.py`) и тонкие делегаты для тех, кто зовёт окно. Крючков в
`main_window/` нет; новая часть — свой класс-поле, не звено цепочки.

## Последствия
Код: `desktop/main_window/` (`company_files.py`, `page_stack.py`, `navigator.py`,
`report_places.py`, `menus.py`, `window.py`); тесты окна не менялись, кроме пяти
обращений к приватному.
