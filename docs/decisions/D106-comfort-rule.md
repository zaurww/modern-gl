# D106 — «Уют» — правило для каждой новой функции
Статус: принято
Дата: 2026-10-23

## Контекст
—

## Решение
**«Уют» — правило для каждой новой функции** (сессия 40; пользователь: «в программе должно быть уютно работаться; взять простотой, удобством, интуитивностью»). Проверяемые правила — пункт «Уют» в чек-листе `docs/ENGINEERING.md`: одна остановка Tab на поле и всё без мыши; каждое число ведёт к документу; одинаковое работает одинаково везде; программа помнит выбор; короткий ввод понимается, понятое видно сразу; пустое место объясняет себя; опасное — с отменой, а не с вопросом; отчёт тихий. В ответе о новой функции — одной строкой, соблюдено ли.
