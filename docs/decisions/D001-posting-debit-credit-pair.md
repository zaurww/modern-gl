# D1 — Проводка = пара Дт/Кт
Статус: принято
Дата: 2026-10-19

## Контекст
—

## Решение
**Проводка = пара Дт/Кт** + сумма (как в 1С 7.7), а не набор строк с признаком стороны. Каждая проводка сбалансирована по построению; анализ счёта по корреспонденции — простой `GROUP BY`. Документ (журнальная запись) содержит 1..N проводок.
