# D-new — Реестр горячих клавиш
Статус: принято
Дата: 2026-10-27

## Контекст
29 `QShortcut` в 18 файлах, легенды клавиш — рукописные строки в двух копиях, банк снимал чужие Enter перебором `findChildren`.

## Решение
Клавиши программы — одна таблица `desktop/shortcuts.py::KEYS`: id, клавиши, scope (WINDOW — всё окно, PAGE — страница, GRID — таблица вне открытой ячейки, TYPED — вводится в таблицу, только в легенде) и описание (`tr`). Привязка — `bind(widget, id, slot)`, `QShortcut(` вне реестра не пишется; легенды — `legend(*ids)`. Две записи с одними клавишами в одном scope запрещены.

## Последствия
Код: `desktop/shortcuts.py`. Тест: `tests/test_shortcuts.py`.
