# D53 — E-qaimə «Təsdiq gözləyir» и сверка с порталом
Статус: принято
Дата: 2026-10-21

## Контекст
—

## Решение
**E-qaimə «Təsdiq gözləyir» и сверка с порталом** (сессия 16, реализовано в сессии 17 — `docs/EQAIME_RECONCILIATION.md`). Импорт берёт ещё и статус `onApproval` (черновик с меткой «Təsdiq gözləyir», проводить можно). При импорте хранится снимок портала по каждой e-qaimə (номер, статус, VÖEN, дата, сумма, ƏDV). Отчёт «Сверка с порталом» за период: список всех статусов с портала против проведённых проводок по номеру e-qaimə (D38) — совпадает / есть на портале, нет в книге / в книге, но аннулирована / суммы / период / контрагент / изменилась с момента импорта / в процессе; итоги без ƏDV и ƏDV портал против книги. Сверенный месяц отмечается; при следующем входе на портал — предупреждение, если после сверки что-то изменилось. Сумма e-qaimə в книге — начисление (кредит расчётного счёта против не-денег; продажа — дебет), ƏDV — по счёту ƏDV против не-денег; оплаты с тем же номером не входят. Сверять можно любой период — день, неделю, месяц (утренняя сверка за вчера); отмечается сверенным любой период, предупреждение — если e-qaimə изменилась после отметки её дня и день не отмечен заново. «Другой период» — только другой месяц (декларация ƏDV месячная); e-qaimə книги считается в день портала, если он в том же месяце. Сверенное за последний год перечитывается при каждом входе; подтверждение (onApproval → approved) изменением не считается.
