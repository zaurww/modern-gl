# D74 — Полная проверка базы — на каждой резервной копии
Статус: принято
Дата: —

—

## Решение
**Полная проверка базы — на каждой резервной копии** (сессия 24, «Архитектурный аудит», п. 1). Копия постраничная, поэтому `PRAGMA integrity_check` копии — полная проверка самой компании; она идёт после каждого сеанса с изменениями (копия при закрытии) и при каждой ручной копии, а открытие остаётся быстрым (`quick_check`). Повреждённая копия не сохраняется и не вытесняет хорошие; пользователь видит, что файл компании нужно восстановить. При восстановлении текущий файл сохраняется побайтно, без проверки: он может не открываться вовсе. Разделение общего файла очищает от чужих компаний каждую таблицу с `company_id` (не список таблиц), после обновления копии до текущей схемы.
