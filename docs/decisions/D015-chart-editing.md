# D15 — Редактирование плана счетов
Статус: принято
Дата: 2026-10-19

## Контекст
—

## Решение
**Редактирование плана счетов**: добавить / изменить / сменить код / скрыть. Удаления нет — скрытый счёт не предлагается при вводе, но остаётся в истории и отчётах. Счёт с проводками нельзя превратить в группу и нельзя менять его субконто. Первый субсчёт у счёта без проводок делает его группой.
