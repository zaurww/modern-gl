# D185 — Один счёт расчётов: авансы на 60/62; ƏDV покупок раскладывает деньги без номера сам
Статус: принято (меняет D78 для новых компаний; уточняет D138, D144, D145)
Дата: 2026-10-29

## Контекст
Пользователь: «лучше один счёт на всех покупателей, чтобы не метаться между авансовыми»;
оператор банка «не всегда может точно знать… что это аванс или нет», номер e-qaimə бывает
неверным или не указан. Сравнение: 1С 8 и SAP держат авансы отдельно из‑за НДС с авансов
(РФ, ЕС) и показа в балансе; Odoo, Xero, QuickBooks — один счёт, переплата — кредит
контрагента. У нас баланс уже делит 60/62 по контрагентам (`FLIPPED`, развёрнутое сальдо),
ƏDV продаж — по деньгам и номеру (D142, D143). Правило ƏDV АР (пользователь): аванс
полученный — ƏDV начисляется; аванс выданный — к зачёту не подлежит, пока нет e-qaimə.
Принцип (пользователь): «нельзя налоговые расчёты сильно привязывать к GL — налоги и
правила меняются, принцип GL нет»; банк по умолчанию ставит 60/62, но можно выбрать 61,
64 и любой счёт.

## Решение
- **Шаблоны новых компаний — без счетов авансов:** classic без 61/64, 1c77 без 60.2/62.2
  (60.1/62.1 остаются субсчетами — место для своих). Переплата остаётся на 60/62 у
  контрагента без номера (банк так уже умел без роли, D78). Счёт авансов можно завести и
  дать роль — всё прежнее работает; старые компании не меняются.
- **ƏDV покупок не опирается на счета:** оплата e-qaimə — только деньги (`credit.money`);
  проводка «Зачёт аванса» (Дт 60 / Кт 60.2 с номером) денег не двигает и не читается.
  Деньги поставщику без номера — на счёте поставщика или авансов (по типу, не по коду) —
  раскладываются модулем на его e-qaimə от старшей: стоимость — на стоимость, ƏDV — на ƏDV
  (`application/vat/purchases.py`); возврат без номера снимается с последних денег.
  Зачёт — не раньше дня e-qaimə (D138). Пример пользователя: 10.03 — 100 и 18 на депозит
  без номера, 20.03 e-qaimə 100 + 18 → 18 к зачёту 20.03.
- Следствие: ƏDV-аванс на депозит поставщика (D145) засчитывается в день e-qaimə, а не в
  день проводки зачёта; предупреждение «оплачено без номера — укажите номер» почти не
  встречается — деньги без номера разложены.
