# D199 — Количество в книге: счета объектов (01, 08, 12) считают штуки
Статус: принято (опирается на D194, D198)
Дата: 2026-11-04

## Контекст
Пользователь: в ОСВ и анализе по ОС и 12 нет количества; на предложение — «делаем».

## Решение
- `postings.quantity` — миллионные доли (`domain/quantity.py`), знак суммы; сторно отрицает.
- Количественный счёт — правило, не флаг (`application/quantities.py`): актив, не
  контрсчёт, субконто — справочник объектов (D194). 01, 08, 12 — да; 10, 41 — нет
  (количество ведёт склад).
- Документ: «Кол-во» перед «Суммой»; покупка передаёт количество строки без товара.
- «Заполнить остатком» (D198) переносит количество; меньше — сумма по средней, правится.
- ОСВ по субконто и карточка — колонки «Количество»; файл обмена — `quantity`.
- Пока без: начальные остатки, ОСВ по счетам, анализ счёта.
