# D209 — Новые товары из вставки создаются при сохранении документа
Статус: принято (уточняет D121)
Дата: 2026-11-06

## Контекст
70 товаров декларации, пробная вставка, строки удалены: имена остались в справочнике и в
«Anbar», удалять — по одному. Пользователь: «Склад должен быть очень надежным модулем». Вставка
писала товары сразу, отдельно от документа, а обрывок имени молча находил чужой товар.

## Решение
- Новое имя из вставки живёт в строке (id меньше нуля) и становится товаром при сохранении,
  одной транзакцией с документом: `Inventory.adding_items`. Не при проведении: черновику нужен
  настоящий товар. Удалили строку, закрыли, сохранение не прошло — товара нет. F7 ничего не оставляет.
- Товар при вставке ищется только по полному имени или коду (`exact_choice`); склад и субконто —
  как раньше, они пишутся сразу.
- Окно новых имён показывает похожие (`similar_choices`: те же буквы без регистра, пробелов и
  знаков или одно имя внутри другого), выбор — «новый» или существующий; похожие скрытые — надпись.
  Окно — при вставке, не при сохранении: строки сразу верны, единица и счёт известны.
- Товар, введённый в ячейке через окно товара, создаётся сразу: это явное действие.
- «⋯ → Удалить неиспользованные товары…» в «Anbar» и в справочнике товаров: список с галочками,
  удаление — всё или ничего.
