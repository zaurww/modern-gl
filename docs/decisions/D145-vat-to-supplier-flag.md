# D145 — ƏDV поставщику с расчётного счёта — признак у оплаты; аванс на депозит платит ƏDV первым; «плательщик ƏDV с даты»
Статус: принято
Дата: 2026-10-25

—

## Решение
**ƏDV поставщику с расчётного счёта — признак у оплаты; аванс на депозит платит ƏDV первым; «плательщик ƏDV с даты»** (ветка `claude/vat-payer`; этап 4; пользователь: можно платить ƏDV с расчётного счёта на депозит поставщика, с депозита или частью так и так; аванс с депозита без номера бывает; до даты регистрации — «не начислять, не зачитывать»). Что деньги на депозит поставщика, по проводке Дт 60 / Кт 51 не видно, поэтому у проводки и строки банковской операции — признак `pays_vat` (миграция 0052): форма оплаты предлагает в поле «Депозит ƏDV» вариант «С этого счёта — на депозит поставщика» (вторая строка той же операции), у строки — галочка «ƏDV»; файл обмена — поле `pays_vat`. Аванс поставщику без номера с депозита (или с признаком) — ƏDV-аванс поставщика: зачёт аванса (Дт 60 / Кт 61 с номером) платит из него ƏDV e-qaimə, остальное — стоимость. `companies.vat_payer_from` (меню компании «Плательщик ƏDV с…»): раньше этого дня обязательства нет, покупки не зачитываются и не предупреждают; отчёты ƏDV говорят это в подвале.
