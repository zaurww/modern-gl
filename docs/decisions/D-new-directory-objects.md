# D-new — Справочник объектов или категорий: признак справочника, не список в коде
Статус: принято (уточняет D173, D174)
Дата: 2026-11-04

## Контекст
Ветка `claude/directory-objects`. Пользователь на e-qaimə из 10 строк малоценки на свой
счёт 12 со своим справочником «Azqiymətlilər»: «копирую в 1-ю строку, они автоматом
появляются во всех 9-и строках… можно случайно пропустить строку». Объекты у каждой строки
были только у кодов `fixed_asset` и `intangible` (D173); справочник пользователя —
категория, элемент расходился по строкам счёта (D174). Отвергнуты: угадывать по классу
счёта (ломается на 97, поведение не объяснимо) и не разносить вовсе (отменено в D174).

## Решение
- У справочника признак **«Объекты: у каждой строки покупки свой элемент»**
  (`subconto_kinds.per_line`, миграция 0063): включён у ОС и НМА, новый справочник —
  категория, пока не включат. Где: «Справочники» → «⋯», пункт с галочкой; состояние —
  в подписи под названием справочника; изменение — в журнал действий.
- Справочник объектов ведёт себя как ОС (D173): элемент не расходится, пустая ячейка
  открывается с названием строки, «Объекты по названиям строк» создаёт разом. Категория —
  как прежде (D174).

## Последствия
Хранение проводок не менялось. Код — `ledger/subconto.py` (`OBJECT_KIND_CODES`,
`set_subconto_kind_per_line`; теги вынесены в `ledger/tags.py`), `Catalog.kind_per_line`,
`inventory_document_page/lines_spread.is_per_line`, `directories_page` (`set_per_line`);
тесты — `tests/test_line_objects.py`.
