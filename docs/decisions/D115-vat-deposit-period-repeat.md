# D115 — ƏDV DH с портала — за период, повтор с вопросом
Статус: принято
Дата: 2026-10-23

## Контекст
—

## Решение
**ƏDV DH с портала — за период, повтор с вопросом** (сессия 43; пользователь: «спрашивает, с какого периода загружать — неудобно, сделать как в alış/satış… и проверку, что на тот же период заново не загружать»; уточняет D112). Окно `bank_page/portal.DepositDialog`: `PeriodBar` как у e-qaimə, по умолчанию — со дня после последней загрузки по сегодня. Операции берутся с начала периода по сегодня (остаток дня считается назад от остатка портала), проводятся только дни периода. Загруженные периоды — `bank_portal_loads` (миграция 0041); период целиком загружен — вопрос «Загрузить снова?» (операции и так не дублируются по референсу). Пункт меню — и в списке счетов на депозите под курсором; у страницы банка одна «⋯» (D86). Окно входа на портал пишет, чего ждёт (`portal_login.waiting_for`).

## Последствия
Код: `bank_page/portal.DepositDialog`.
