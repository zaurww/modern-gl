## Решение
**«Карточка субконто» — проводки элемента по всем счетам, с остатком** (сессия 51, пара к D125, как в 1С 7.7). Открывается двойным щелчком из «Анализа субконто»: по строке элемента — по всем счетам, по строке счёта под ним — только этот счёт (группа — с субсчетами). Строка — проводка с обоими счетами и суммой на той стороне, где элемент; стоит он на обеих (Дт 62.1 [S-002] / Кт 60.1 [S-002]) — обе суммы, остаток не меняется. Остаток — чистый по всем счетам с элементом: по контрагенту — «должны нам минус должны мы», по заказу — с выручкой; на одном счёте — обычная карточка. Щелчок по строке — документ. `reporting/reports/subconto_card.py` (один проход по проводкам с `on_dt`/`on_ct`, остаток — оконной суммой), `reports_page/subconto_card.py`, в `REPORTS` под именем `subconto_card` (элемент — `params.subconto[0]`, счёт 0 — все). В «Все отчёты» не вынесена: путь — через анализ. Не сделано: валютные суммы в строках.
