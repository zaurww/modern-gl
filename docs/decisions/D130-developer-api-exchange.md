## Решение
**Для разработчиков: формат обмена документами, публичный API, командная строка** (сессия 57; пользователь: «чтобы программу сделать привлекательной для девелоперов… добавлять, настраивать», «можешь начинать… первые обязательные этапы»; план — `docs/EXTENSIBILITY.md`). Внешняя программа подключается файлом, а не общей базой (CONCEPT §4): JSON `modern-gl/documents` с версией (`docs/EXCHANGE.md`) — счета по коду, справочники по точному имени, суммы строкой, сторно `reverses`; всё или ничего; пара (`source`, `id`) в `document_sources` (миграция 0049) — повтор без дублей; по умолчанию черновики. Выгрузка — тот же формат. `modern_gl.api` (`API_VERSION = 1`, `docs/API.md`) — единственная обещанная поверхность, остальное внутреннее; пишет только через `Ledger`, автор «API · …»; `modern-gl-cli` — то же из консоли. Плагины в процессе — не сейчас (меняют рамку). Код — `application/exchange/`, `reporting/exchange.py`, `api/`; контракт — `tests/test_api.py`, `tests/test_exchange.py`.
