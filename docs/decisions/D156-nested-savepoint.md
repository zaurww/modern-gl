# D156 — Вложенная транзакция — savepoint
Статус: принято
Дата: 2026-10-27

## Контекст
`db.transaction` внутри открытой транзакции просто выполнял блок: ошибка одного документа в цикле («Провести все», удаление отмеченных, импорт) меняла смысл обещанной изоляции, а модули держали пять ручных `SAVEPOINT` сырым SQL.

## Решение
Вложенный `transaction()` — `SAVEPOINT sp_N` с уникальным именем: при исключении `ROLLBACK TO` + `RELEASE`, при успехе `RELEASE`; внешняя транзакция продолжается. `db.dry_run(conn)` — блок, который откатывается всегда: предпросмотр загрузки — это сама загрузка, откаченная, они не расходятся. Ручные savepoint вне `db.py` запрещены; сценарий — по-прежнему один метод `Ledger`/модуля (D93).

## Последствия
Код: `infrastructure/db.py` (`transaction`, `dry_run`). Тест: `tests/test_transactions.py`.
