## Решение
**Журнал проводок в текстовом формате hledger — только выгрузка** (сессия 30; сценарий: клиент уходит — новая фирма получает весь учёт текстом, который читается без нашей программы; заодно независимая сверка отчётов). Журнал — производное, как отчёт: источник правды — база, обратного импорта нет. Документ = транзакция `дата (номер) содержание`, проводка Дт/Кт = две строки; только проведённые документы книги (список слоёв), корректировки помечены тегом слоя, сторно — тегом с номером исходного. **Все суммы в манатах**, как в ОСВ: валютная сторона несёт тег `валюта: 500.00 USD` (без записи `@@` — тогда сальдо hledger совпадает с ОСВ без ключей и переоценка не даёт смесь валют). Субконто, e-qaimə, примечание строки — теги; имена счетов — путь `код название` от группы; счета объявлены с типом (`type: A/L/E/R/X`), поэтому `hledger bs`/`is` работают сразу. Код — `reporting/plaintext.py` (ядро), скрипт `scripts/export_hledger.py`; тест `test_plaintext.py` сверяет сальдо из текста с ОСВ и, если hledger установлен, через сам hledger. Позже: «Передача дел…» в интерфейсе (zip: журнал по годам с входящими остатками, план счетов, контрагенты с VÖEN, курсы, ОСВ, README).
