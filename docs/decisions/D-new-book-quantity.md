# D-new — Количество в книге: счета объектов (01, 08, 12) считают штуки
Статус: принято (опирается на D194, D198)
Дата: 2026-11-04

## Контекст
Пользователь: в ОСВ по субконто и анализе по ОС и 12 «Azqiymətlilər» нет количества —
«при ведомости и анализе… информации нету»; на предложение (количество в проводке, в
отчётах, в «Заполнить остатком», частичное списание по средней) — «делаем».

## Решение
- У проводки — количество (`postings.quantity`, миллионные доли единицы, как у склада —
  `domain/quantity.py`); знак — как у суммы, сторно его отрицает. Пусто — не указано.
- **Какой счёт количественный — не флаг, а правило** (`application/quantities.py`):
  счёт актива, не контрсчёт, у которого субконто — справочник объектов («у каждой строки
  свой элемент», D194: ОС, НМА, справочник 12 пользователя). 01, 08, 12 — да; 02, 26, 60
  — нет. Товары (10, 41) — нет: их количество ведёт склад, его проводки — без количества.
- Проведение: количество — только на количественном счёте, с тем же знаком, что сумма.
- Документ: колонка «Кол-во» перед «Суммой» — видна, пока строка на таком счёте;
  вставка из Excel по заголовку «Кол-во»/«Количество».
- Покупка: строка без товара на количественный счёт отдаёт своё количество в проводку.
- «Заполнить остатком…» (D198) переносит и количество; меньше введённое — сумма своей
  доли по средней (3 стула из 10 — 3/10 суммы), сумму можно поправить.
- Отчёты: ОСВ по субконто — «Количество: на начало, приход, расход, на конец»; карточка
  счёта — «Приход, Расход, Остаток». Файл обмена — поле `quantity`.
- Пока без количества: начальные остатки, ОСВ по счетам и её развороты, анализ счёта.
