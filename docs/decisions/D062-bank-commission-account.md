# D62 — Счёт комиссии банка выбирается в модуле «Банк»
Статус: принято
Дата: 2026-10-21

## Контекст
—

## Решение
**Счёт комиссии банка выбирается в модуле «Банк»** (сессия 18, жалоба пользователя: «+ Bank komissiyası» ставит 80 — так в шаблоне классического плана). «Bank → ⋯ → Настройки банка…» — счёт по умолчанию (роль `bank_fee`; та же роль у конвертации, где её по-прежнему можно задать в «Счетах конвертации»). Строка комиссии в операции — обычная строка, её счёт можно сменить. Шаблон классического плана не менялся.
