# D141 — Реестр знает, сверен ли его период с порталом; отметка «сверено» помнит книгу

Дата: 2026-10-25

## Контекст
—

## Решение
**Реестр знает, сверен ли его период с порталом; отметка «сверено» помнит книгу** (ветка `claude/vat-portal`; этап 2 «Этапов до декларации ƏDV»). Сверка по номерам уже была (D53, D118) — отдельная не нужна: реестр берёт e-qaimə тем же `book_invoices` (перенесён в `application`) и показывает по покупкам и продажам одно из «изменились в книге», «изменились на портале» (с номерами), «не сверены» (какой-то день периода без отметки), «сверены»; «⋯» открывает сверку того же периода. Отметка хранит отпечаток e-qaimə периода (номер, сумма, ƏDV, контрагенты — `book_digest`, миграция 0051): правка после сверки (D140) делает отметку недействительной, в окне сверки её можно поставить снова. Старые отметки без отпечатка принимаются как есть. ГТД на портале нет — их не сверяют.
