# D28 — Валютный учёт — признак счёта, три режима
Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**Валютный учёт — признак счёта, три режима** (миграции 0008, 0009): «только в манатах», «только в валюте» (52: каждая проводка с валютой) и «в манатах и в валюте» (60, 62: местные и иностранные контрагенты на одном счёте; проводка без валюты — в манатах). Валюта элемента справочника (USD-счёт банка, договор в EUR) обязательна для его проводок. Режим счёта с проводками меняется, только если старые проводки ему соответствуют; на счёт, где уже лежит валюта другой стороны (Кт 51 при Дт 52 в USD), валютный учёт не включается. Переоценивается только валютная часть.
