# D50 — Договор (müqavilə) необязателен
Статус: принято
Дата: 2026-10-21

## Контекст
—

## Решение
**Договор (müqavilə) необязателен** (сессия 15, вариант пользователя из трёх: необязателен / «Основной договор» как в 1С / добавлять на месте). У многих поставщиков договора нет — только e-qaimə. Субконто вида с владельцем (договор принадлежит контрагенту) при проведении может остаться пустым — и в учёте (`Ledger` `_validate_subconto`), и в формах покупки/продажи/склада; остальные субконто, в т.ч. контрагент, обязательны. В ОСВ по субконто пустое — строка «<не указано>». «Основной договор» не создаём: сотни одинаковых договоров засоряют справочник и обессмысливают отчёты по договорам. Позже — настройка по счёту «обязательно / можно / нет».
