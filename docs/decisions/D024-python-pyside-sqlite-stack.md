# D24 — Python + PySide6 + SQLite остаются стеком локальной однопользовательской версии
Статус: принято
Дата: 2026-10-19

## Контекст
—

## Решение
**Python + PySide6 + SQLite остаются стеком локальной однопользовательской версии.** Они подходят для предметной логики, точных расчётов, настольного интерфейса и переносимого файла компании. Смена языка сама по себе не решает масштабирование. При многопользовательской работе сначала отделить серверный application/API слой и перенести хранение в PostgreSQL; существующее доменное ядро и тестовые примеры сохранить. Тяжёлые отчёты до этого выносить из UI-потока и оптимизировать по измерениям.
