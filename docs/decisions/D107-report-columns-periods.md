## Решение
**Колонки отчёта: по месяцам, по кварталам, сравнение с периодом — концепция** (сессия 40; пользователь: «баланс или P&L по месяцам рядом, или сравнительный период — задокументировать»). Описано в `docs/REPORTING.md`, раздел «Колонки финансовых отчётов». **Сделано** (та же сессия): «Колонки: … ▾» рядом с периодом — Один период · По месяцам · По кварталам · С прошлым периодом · С прошлым годом (запоминается). Расчёт — `reporting/columns.py`: сумма строки — `Amounts`, по числу на колонку, построители отчётов складывают их как числа, строка видна, если есть хоть одна цифра; «Итого» месяцев — ещё одна колонка, посчитанная тем же кодом за весь период (деньги на начало и конец в ДДС — не сумма месяцев). Баланс — на конец каждого месяца, без «Итого»: обороты по отрезкам между датами и нарастающий итог (не чтение с начала на каждую дату); ДДС — один запрос, сгруппированный по дню и паре счетов; ОПиУ — запрос на каждую колонку (≤ 14; на 100 000 проводок 1,2 с против 0,6 с за год — приемлемо). Больше 13 месяцев — по кварталам. Сравнение: «Разница» и «%» (процент — в сотых, как деньги: так же показывается и уходит в Excel; без базы — прочерк). Двойной щелчок по ячейке месяца — карточка за этот месяц. Страница — `desktop/reports_page/statement_columns.py`.
