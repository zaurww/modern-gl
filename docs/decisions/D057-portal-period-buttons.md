## Решение
**Период в окнах портала — кнопками** (сессия 18, запрос пользователя; уточняет D53). В сверке и в загрузке e-qaimə с портала — одинаковый ряд: «Dünən» (в понедельник — пятница–воскресенье), «Bu həftə», «Əvvəlki həftə», «Bu ay», «Əvvəlki ay», «İxtiyari dövr». «Bu həftə / Bu ay» — с понедельника / 1-го по вчера в сверке (утренняя сверка смотрит законченные дни) и по сегодня в загрузке; «Əvvəlki» — целая календарная неделя / месяц. Даты быстрого периода — текстом; поля дат появляются только у «İxtiyari dövr». Сверка открывается с периодом вида последней отметки (по её форме на день отметки), без отметок — «Bu ay».
