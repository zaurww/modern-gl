# D236 — Окно «AI-помощник»: программа сама подключает книги к Claude; своего чата нет
Статус: принято (дополняет D83, D84, D234)
Дата: 2026-11-27

## Контекст
Подключение делалось руками: команда в терминале, флаг `--allow-edits` PowerShell «съел»,
перезапуск. Пользователь: «а можно в самой программе сделать окно для подключения, и писать
запросы прямо там?»; на совет «окно подключения — да, чат пока нет» — «делай окно
„AI-помощник“». Работник с ChatGPT или другой моделью — пока предположение.

## Решение
- Меню компании и Ctrl+K → «AI-помощник…»: где (Claude Desktop, Claude Code — что
  установлено) и что разрешено (чтение · черновики · правки); «Применить» пишет запись
  `modern-gl` в настройки AI-программы, снятая галочка — убирает её.
- Программа меняет **только свою запись**; остальное в файле остаётся; файл, который не
  читается, не переписывается; запись — целиком или никак.
- Сервер `modern-gl-mcp.exe` ставится установщиком рядом с программой — окно берёт его оттуда.
- Свой чат в программе не делается (D83, п. 4 — «если понадобится»): ждёт настоящего случая.

Отклонено: вызывать `claude mcp add` — нужен `claude` в PATH и кавычки через `.cmd`.
