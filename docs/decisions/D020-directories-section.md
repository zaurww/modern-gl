## Решение
**Раздел «Справочники» (Soraqçalar)**: элементы субконто (банки, контрагенты, договоры…) заводятся заранее, переименовываются (история не страдает — ссылки по id) и скрываются (не предлагаются при вводе, остаются в истории). Пользователь может создать свой справочник (например, «Проекты») и подключить его к счёту. Сортировка списков — по азербайджанскому алфавиту.
