## Решение
**Полосы (зебра) в таблицах — по желанию, по умолчанию выключены** (сессия 40; пользователь: «зебра мне не очень нравится»). Меню компании → «Оформление» → «Полосы в таблицах»; `reports_page/table.py::zebra()` (`QSettings` `reports/zebra`); страницы перестраиваются сразу. Тесты держат `QSettings` каждый в своём файле (`tests/conftest.py::own_settings`), не в реестре.

## Последствия
Код: `reports_page/table.py::zebra()`, `reports/zebra`, `tests/conftest.py::own_settings`.
