# D36 — VÖEN контрагента; нерезидент без VÖEN

Дата: 2026-10-20

## Контекст
—

## Решение
**VÖEN контрагента; нерезидент без VÖEN** (миграция 0014): у элемента справочника «Контрагенты» — признак «нерезидент», `tax_id` и страна. Резидент: VÖEN — 10 цифр (пробелы убираются), может быть пустым (физлицо). Нерезидент: страна и налоговый номер своей страны в любом формате. Одинаковый VÖEN у двух контрагентов разрешён (филиалы) — окно спрашивает. Контрагент находится по VÖEN при вводе (ячейка, быстрая строка); колонка VÖEN в справочнике и ОСВ по субконто. Признак нерезидента — задел для ƏDV за нерезидента и налога у источника выплаты. Следом (обсуждено с пользователем): проект — отдельное измерение строки проводки на любом счёте, не субконто (лимит 3 субконто); e-qaimə — сначала реквизит строки, остатки по каждой e-qaimə — позже и по желанию.
