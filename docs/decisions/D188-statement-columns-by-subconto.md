# D188 — Колонки ОПиУ по субконто, строки под группами плана, процент от выручки
Статус: принято
Дата: 2026-10-29

## Контекст
Ресторан с 11 точками, учёт по Uniform System of Accounts for Restaurants: нужны P&L
точки, сводный с точками в колонках, разделы с подытогами и % от продаж. Пользователь:
программа не только для ресторана — делать универсальное; POS пока не трогать.

## Решение
- Точка, филиал, проект — субконто (как D124), Head Office — его элемент.
- «Колонки: по субконто ‹справочник›» в ОПиУ (расширяет D107): колонка на элемент,
  встреченный в периоде (по месту справочника на счёте), «Не указано», «Итого» тем же
  кодом. Предлагаются справочники счетов доходов и расходов. Баланс и ДДС — без него.
- «По счетам» показывает группы плана строкой с суммой, счета под ними по глубине;
  единственный узел уровня не повторяется. Формат отчёта задаёт план — без новых типов.
- «Процент от выручки» — после каждой колонки «%» от строки «Выручка» той же колонки.
- Не делается: Prime Cost (сквозной подытог), распределение общих расходов, шаблон USAR.
