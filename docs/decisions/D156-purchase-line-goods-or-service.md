# D156 — Строка покупки — «Товар» или «Услуга»; для чего купленное — решает счёт товара
Статус: принято
Дата: —

## Контекст
—

## Решение
**Строка покупки — «Товар» или «Услуга»; для чего купленное — решает счёт товара** (ветка `claude/eqaime-items`; пользователь: «программа не может с точностью определить товар ли это или услуга, на код нельзя надеяться… а может просто mal или xidmət? сценариев может быть много… покупаем что-то для себя и помещаем на склад» — «давай»). Вид строки отвечает на один вопрос: идёт ли покупка через склад. Товар для продажи, материалы для себя, малоценка — тот же «Товар» с разным счётом запасов в карточке товара (как номенклатура и её счёт учёта в 1С); услуга, ОС, расходы будущих периодов — «Услуга» со счётом строки. Колонка «Вид» в покупке видна, когда в ней есть строка-услуга; «Товар» у такой строки открывает окно «Строки — товары»: отмечены она и другие услуги без счёта, единица и счёт запасов спрашиваются раз, товары по названиям строк (имя, которое уже есть, — тот же товар) — `Inventory.add_named_items`, одна транзакция; склад — тот, куда идут другие товары документа, иначе первый. «Услуга» у товарной строки оставляет имя товара текстом. «+ Добавить «…»» в имени строки-услуги теперь спрашивает новый товар. Следующая e-qaimə с тем же названием — сразу товар (D45).
