# D-new2 — Выписка из файла: ни одна строка не пропадает молча
Статус: принято
Дата: 2026-11-27

## Контекст
Параллельная работа: долларовая выписка загружена одна, две строки пополнения с манатного счёта
молча пропали. Окно давало IBAN только загружаемого файла, а «уже есть» решалось по референсу
без счёта — банк даёт обеим сторонам перевода один референс.

## Решение
- Другая сторона перевода и конвертации ищется среди всех счетов, известных по IBAN.
- «Уже есть» — по (референс, счёт): операция счёта, счёт, куда идёт перевод, сторона конвертации.
- Сторона конвертации, которой нет в файлах загрузки, берётся из уже загруженной операции
  другого счёта (она заменяется, как прежде; закрытый период — отказ, как прежде).
- Перевод в одной валюте: другая сторона ждала счёта — получает его и проводится; ушла на
  другой счёт (57) — эта строка туда же, черновиком со ссылкой на номер.
- У каждой строки файла есть строка в окне: не загруженная — «не загружена: причина».
  Итог: сколько строк, из чего разница с банком (остаток на начало, незагруженные строки).
