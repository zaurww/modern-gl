## Решение
**Коммерческий целевой пользователь — бухгалтер-консультант: один сотрудник ведёт несколько фирм.** Первоначальная коммерческая версия локальная и offline-first; отдельный файл SQLite на фирму соответствует единице обслуживания, резервного копирования и передачи. Одновременное редактирование одной фирмы несколькими сотрудниками не поддерживается. Живой `.gl`-файл нельзя совместно открывать с сетевого диска или синхронизируемой облачной папки; для передачи используются проверенная резервная копия/экспорт и явное подключение файла.
