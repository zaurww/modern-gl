# D116 — Колонки отчёта выбирает пользователь; редкие скрыты
Статус: принято
Дата: —

## Контекст
—

## Решение
**Колонки отчёта выбирает пользователь; редкие скрыты** (сессия 44; «в ОСВ по субконто 60 и в qaimələr появляется VÖEN, он не нужен; нужна минимальная customization; в плане счетов после первого столбца слишком большое пустое место»). Правый щелчок по заголовкам или «⋯ → Колонки…» — галочки колонок; пара Дт/Кт под одной подписью — одна галочка; первая колонка всегда видна; «Колонки по умолчанию» — сброс. Выбор запоминается на вид отчёта (`reports/columns/<вид>`, QSettings), а не на компанию. `Column.optional` — скрыта, пока не попросят: VÖEN в ОСВ по субконто и e-qaimə (поиск по VÖEN остаётся). Пустое место — справа от таблицы, не после названия (Jon Moon, D52): план счетов, e-qaimə, покупки и продажи — без растянутой колонки. Финансовая отчётность — своя «Колонки ▾» (D107). Ширины и порядок мышью — D177.

## Последствия
Код: `reports/columns/<вид>`.
