# D31 — Регламентированная отчётность — отдельные пакеты, GL не меняется
Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**Регламентированная отчётность — отдельные пакеты, GL не меняется** (концепция, не реализовано). Ядро отдаёт только факты (сальдо/обороты по счёту × субконто × слой × период) на чтение; налоговые/статистические формы — версионируемые пакеты: форма, сопоставление счетов со строками, ставки с `valid_from`, формулы, рендереры (PDF/Excel/XML e-taxes/XBRL). Модуль не пишет в GL (только черновик документа), сданный отчёт замораживается снимком. Факты отчёта хранятся в модели, совместимой с XBRL. Подробно: [`docs/REPORTING.md`](REPORTING.md).
