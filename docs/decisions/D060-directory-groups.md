## Решение
**Группы (папки) в справочниках, как в 1С** (сессия 18; пользователь: «не знаю, должно быть удобно для многих» — решение предложено). Одинаково для любого справочника (товары, контрагенты, статьи затрат…): `subconto_values.is_group` + `parent_id` (миграция 0027), вложенность разрешена, но обычно хватает одного уровня. Группа — только для поиска и отчётов: в проводку, документ или список ввода не попадает (`Catalog.values` без групп, проверка при проведении). «Soraqçalar»: «+ Qrup», дерево (группа жирным с иконкой папки и числом элементов, элементы с отступом), новый элемент — в выбранную группу, «Qrupa köçür…» (группа — со всем содержимым; в себя нельзя), удалить группу можно только пустую (D59). Товар: в окне товара — «Qrup», а пока по товару нет документов — также единица и счёт запасов (`Inventory.update_item`); окно открывается из «Soraqçalar» (F2 на товаре) и двойным щелчком в «Anbar». «Anbar»: остатки по группам с итогом стоимости группы, без группы — в конце. Не сделано: поиск в списках ввода по названию группы; итоги по группам в ОСВ по субконто.
