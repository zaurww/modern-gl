# D121 — Склад: сначала проверить и сравнить, потом отчёты; первый товар — без настройки
Статус: принято
Дата: 2026-10-24

## Контекст
—

## Решение
**Склад: сначала проверить и сравнить, потом отчёты; первый товар — без настройки** (сессия 48; пользователь: «сперва нужно протестировать как работает склад… сравнил… с Zoho Inventory, QuickBooks, Katana, ERPNext… в Logo ERP очень удобный отчёт ətraflı maliyyət analizi… После уже будем думать об отчётности»; инвентаризация отложена). Итог сравнения: у нас документ без заказов, мгновенный пересчёт средней задним числом, доп. расходы делятся на остаток и проданное; нет возвратов, единиц с пересчётом, минуса, инвентаризации, отчётов склада. Сделано: окно товара предлагает обычные единицы, выбранная и «Основной склад» (если складов нет) создаются с товаром одной транзакцией (`Inventory.add_new_item`); документ склада помещается в 1280 px; пустой «Склад» — кнопки «+ Товар», «+ Покупка», «Начальные остатки». Дальше — живая проверка, затем отчёты (ориентир — Logo «Ayrıntılı Maliyet Analizi»).
