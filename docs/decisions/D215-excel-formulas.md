# D215 — Excel с формулами
Статус: принято (развивает D104)
Дата: 2026-11-12

## Контекст
Пользователь сравнивал программу с VT Transaction+, где отчёты уходят в Excel с живыми формулами:
«мне нужно тоже … ексель с формулами». До этого «В Excel» писал только числа.

## Решение
- Итог, под которым стоят строки (счёт над субсчетами, группа над статьями), — `SUBTOTAL(9, …)`
  его строк; строка итога внизу (с чертой в отчёте) — `SUBTOTAL` всего, что выше, от прошлого
  такого итога. `SUBTOTAL` не считает вложенные `SUBTOTAL`, поэтому ничего не задваивается.
- Конечное сальдо ОСВ — из начального и оборотов: одной колонкой `=нач+Дт−Кт`, двумя —
  `MAX(0, …)` на свою сторону. Колонка знает свою роль (`Column.role`: `opening`, `turnover_dt`…).
- Формула пишется, только если даёт ровно цифру отчёта; иначе — число (развёрнутое сальдо на обе
  стороны, итог, который не сумма). Файл не может разойтись с отчётом.
- Excel считает формулы при открытии (`fullCalcOnLoad`); Ctrl+C — по-прежнему числа.

## Последствия
`infrastructure/report_formulas.py`, `report_file.py` (`ReportColumn.role`, `ReportRow.total`,
`ReportTable.with_formulas`), `desktop/reports_page/export.py`. Тесты — `tests/test_excel_formulas.py`
(цифры вручную и вся ОСВ: каждая формула равна цифре отчёта). Дальше возможно: лист «Проводки» и
отчёт `SUMIFS` от него; формулы ОПиУ (прибыль = выручка − расходы) — ролями, как у ОСВ.
