# D37 — Конвертация валюты — отдельный документ «Конвертация валюты», не шаблон операции
Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**Конвертация валюты — отдельный документ «Конвертация валюты», не шаблон операции** (реализовано в сессии 11, миграция 0018: роли `fx_transit` / `fx_gain` / `fx_loss` / `bank_fee`; черновик хранится без проводок; зачисление позже — второй документ GL той даты; комиссии — строками (миграция 0020): каждая со своего счёта (любая сторона или третий счёт) в его валюте, по курсу дня документа, в который попадает (со счёта зачисления — в документ зачисления); проводки конвертации меняются только через неё; транзитный счёт без выбранного — по типу `transit`; в «classic» — 57 и 80; не найден счёт — форма сразу спрашивает его). Шаблон не подходит: он не считает разницу курса банка и ЦБА, не умеет валюту, не справляется с валютой на обеих сторонах (EUR→USD), не проверяет, что 57 закрылся в ноль. **Поля:** дата; «Списано с» — счёт + субконто (банковский счёт) + сумма в его валюте; «Зачислено на» — счёт + субконто + сумма в его валюте; комиссия банка (сумма, счёт, с какого счёта списана). Направления: валюта→манаты, манаты→валюта, валюта→валюта. **Проводки** (строятся документом, через транзитный 57 — роль счёта, D34): Дт 57 / Кт счёт списания — по курсу ЦБА на дату; Дт счёт зачисления / Кт 57 — по курсу ЦБА (для манат — сумма); разница на 57 → Дт 91.2 / Кт 57 (убыток) или Дт 57 / Кт 91.1 (доход) со статьёй «Курсовая разница при конвертации»; комиссия: Дт 91.2 (или 26) / Кт банк. Счета разницы, статья и счёт комиссии — роли счетов в настройках, по умолчанию из шаблона плана. Под формой — курс ЦБА, курс банка (вычисленный) и разница. Курс ЦБА нет на дату — плашка «Загрузить курс ЦБА», как в документе. Исправление — как у остальных документов (D32). **Задел под будущий импорт банковской выписки** (запрос пользователя): (1) у каждой стороны необязательная ссылка на банковскую операцию (референс из выписки) — импорт по ней (или по банк + дата + сумма) находит уже введённый документ и помечает строки выписки «учтено» вместо повторной проводки (match/create, как в Xero/QuickBooks); не найдя — создаёт черновик «Конвертации» из двух строк выписки, расчёт тот же; (2) дата зачисления может отличаться от даты списания (банк зачисляет на следующий день): разница — на дату списания, до зачисления деньги на 57; (3) черновик сохраняется без второй стороны (пришла выписка только по EUR-счёту), вторая выписка его дополняет. Правило: у конвертации один владелец — этот документ; импорт выписки проводок по конвертации сам не строит.
