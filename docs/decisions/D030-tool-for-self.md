# D30 — Цель — удобный и гибкий инструмент для себя, не продажа
Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**Цель — удобный и гибкий инструмент для себя, не продажа** (уточняет D25). Модульность: ядро (главная книга, справочники, валюты) самодостаточно; модули (склад, позже ОС, e-qaimə) — со своими таблицами, связаны с ядром только проводками и справочниками, ими можно не пользоваться. Внешние программы пользователя (расширение etax-ext, программа учёта ОС) подключаются через импорт документов.
