## Решение
**Модульность и масштабируемость — постоянная концепция** (сессия 21, после аудита по просьбе пользователя: «записать как концепт и проверять при каждой новой функции»; развивает D24, D30; размер кода — D70). Принципы, чек-лист новой функции и список долга — `docs/ENGINEERING.md`: ядро не знает о модулях (не читает их таблиц и не импортирует их код), модуль — свой пакет и свои таблицы, слои (domain без SQL/Qt, Qt только в desktop, SQL не в виджетах), размер кода — пределы D70, объём данных — агрегация в SQL, фон по замерам. Автоматически проверяет `tests/test_architecture.py`; нынешние нарушения — явные исключения в нём, каждое — пункт долга; погашенный долг тест требует убрать из исключений. Добавлять исключение — только с записью причины в «Долг».
