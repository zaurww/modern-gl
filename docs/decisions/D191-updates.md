# D191 — Обновление из программы: спросить GitHub при запуске и раз в час, тихая установка
Статус: принято
Дата: 2026-11-03

## Контекст
Коллега-тестировщик не технарь: скачивать установщик с GitHub и ставить его руками после
каждой правки — работа пользователя. Слова пользователя: «коллега заметил, я поправил, у него
появился знак UPDATE, нажал — готово».

## Решение
- **При каждом запуске и затем раз в час** установленная программа (PyInstaller,
  `sys.frozen`) спрашивает у GitHub последний Release (`/releases/latest`, 8 с, в фоне, молча
  при любой ошибке): исправление доходит до коллеги сразу, не назавтра (было «раз в день» в 0.1.4). Из исходников (`uv run modern-gl`) — не спрашивает.
- **Строка внизу боковой панели** «Вышла версия 0.1.4 — обновить» — красная кнопка
  («ярким цветом, чтобы заметить», «красным»; D86: ждущее громче);
  иначе ничего не показывается.
- **По щелчку** — скачать setup.exe во временную папку (показан процент), запустить тихо
  `/SILENT /CLOSEAPPLICATIONS` через `cmd … /wait … & start modern-gl.exe`: установщик сам
  закрывает программу (D189, `CloseApplications=yes`) и после установки программа запускается
  снова — обновлённая или прежняя, если установку отменили. Файлы компаний не трогаются.
- Версии сравниваются по числам (0.1.10 новее 0.1.9).

## Последствия
`infrastructure/github_releases.py` (сеть), `application/updates.py` (смысл: новее, раз в
день, команда установки), `desktop/updater.py` (фон, строка, запуск), `sidebar.new_version`,
`app.py`; перевод `i18n_az/updates.py`; `tests/test_updates.py`.
