# D48 — «Сохранить как» для компании
Статус: принято
Дата: 2026-10-20

## Контекст
—

## Решение
**«Сохранить как» для компании** (сессия 14): копия открытой компании в любое место под новым названием (название в файле меняется, чтобы в меню не было двух одинаковых), дальше работа идёт в новом файле, старый остаётся как был (как в Word/Excel). «Сохранить копию» по-прежнему только пишет копию. Файлы вне рабочей папки запоминаются в настройках и показываются в меню компаний. «Новая компания» тоже спрашивает, куда сохранить файл (по умолчанию — рабочая папка). «Добавить из файла» (уточняет D18) открывает файл с одной компанией на месте, без копирования; общий файл с несколькими компаниями раскладывается в рабочую папку, как раньше.
