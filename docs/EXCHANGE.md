# Файл обмена документами — `modern-gl/documents`, версия 1

Для разработчиков других программ (D130). Так другая программа (etax-ext, учёт ОС,
интернет-магазин) передаёт проводки в Modern GL, а Modern GL отдаёт их обратно. Формат —
JSON в UTF-8. Код — `application/exchange/` (чтение), `reporting/exchange.py` (выгрузка);
API и командная строка — `docs/API.md`.

## Пример

```json
{
  "format": "modern-gl/documents",
  "version": 1,
  "source": "etax-ext",
  "documents": [
    {
      "id": "S-2026-0001",
      "date": "2026-03-05",
      "memo": "Satış, qaimə 311",
      "postings": [
        {
          "debit": "211",
          "debit_subconto": ["Bakı Elektrik"],
          "credit": "601",
          "amount": "100.00",
          "e_qaime": "MT2603000311"
        },
        {
          "debit": "211",
          "debit_subconto": ["Bakı Elektrik"],
          "credit": "521.1",
          "amount": "18.00"
        }
      ]
    },
    {"id": "S-2026-0002", "date": "2026-03-09", "reverses": "S-2026-0001"}
  ]
}
```

## Поля

**Файл.** Лишнее поле — ошибка (опечатка не пройдёт молча).

| Поле | Обязательно | Что |
|---|---|---|
| `format` | да | всегда `"modern-gl/documents"` |
| `version` | да | целое; программа читает версии до своей, новее — отказ «обновите программу» |
| `source` | да | имя программы-источника; вместе с `id` документа — ключ от дублей |
| `documents` | да | список документов |

**Документ.**

| Поле | Обязательно | Что |
|---|---|---|
| `id` | да | номер документа в программе-источнике (строка); уникален внутри `source` |
| `date` | да | `"ГГГГ-ММ-ДД"` |
| `memo` | нет | содержание |
| `layer` | нет | `common` (по умолчанию), `ifrs_adj`, `tax_adj` — слой параллельных книг (D7) |
| `postings` | да, кроме сторно | строки Дт/Кт |
| `reverses` | нет | вместо `postings`: красное сторно документа с этим `id` того же источника (D5) |

**Строка проводки.**

| Поле | Обязательно | Что |
|---|---|---|
| `debit`, `credit` | да | код счёта, точно как в плане счетов компании; счёт — не группа |
| `amount` | да | сумма в манатах **строкой**: `"118.00"` (число JSON приходит как float — отказ) |
| `debit_subconto`, `credit_subconto` | по счёту | список имён элементов по порядку субконто счёта: имя, VÖEN или код; `""` — пропустить позицию |
| `currency`, `currency_amount` | для валютного счёта | код валюты и сумма в ней строкой |
| `e_qaime` | нет | номер e-qaimə (D38) |
| `customs` | нет | номер таможенной декларации — вместо `e_qaime` |
| `pays_vat` | нет | `true` — ƏDV поставщику с расчётного счёта на его депозит (D145) |
| `memo` | нет | примечание строки |

## Как читается
- **Всё или ничего.** Хоть одна ошибка — не записывается ни один документ; в ответе —
  все ошибки с `id` документа, не только первая.
- **Имена — точно.** Счёт — только по коду; элемент справочника — по точному имени, VÖEN или
  коду, без поиска по части имени. Элемента нет — ошибка: справочник ведёт человек в
  программе. Договор ищется среди договоров своего контрагента (контрагент — раньше в
  строке).
- **Повтор без дублей (D72).** Документ помечается парой (`source`, `id`); тот же файл
  второй раз ничего не создаёт — документ назван в ответе как «уже есть», даже если в файле
  его изменили. Удалили документ в программе — следующий импорт создаст его снова.
- **Черновики по умолчанию.** Документы приходят черновиками — человек проверяет и
  проводит; проведёнными — по явному флагу (`post`). Те же проверки, что при вводе руками:
  закрытый период, обязательные субконто, валюта счёта (D5, D28).
- Сторно (`reverses`) — всегда проведённое; исходный документ — того же `source`, уже в
  программе или раньше в этом же файле.
- Документ модуля (банк, склад) из выгрузки приходит в другую компанию обычными
  проводками журнала — первичный документ модуля не переносится.

## Выгрузка
Проведённые документы периода одной книги — в этом же формате: `id` — номер документа,
`source` — `"modern-gl/<название компании>"`, сторно — через `reverses`. Выгрузку можно
загрузить в другую компанию с тем же планом и справочниками. Счёт без кода выгружается
именем — такая строка обратно не загрузится (D22).

## Версии
Новое необязательное поле или новое значение — следующая версия; старые файлы читаются
всегда. Программа отказывает файлу новее себя, а не угадывает. Изменения — в журнале ниже.

| Версия | Что |
|---|---|
| 1 | сессия 57: документы, проводки, субконто по именам, валюта, e-qaimə и декларация, слой, сторно |
