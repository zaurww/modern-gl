# Дизайн: страницы и отчёты

Одно место для правил вида (D86, D103, D116, D127). Читать перед новой страницей, новым
отчётом или правкой вида; при расхождении — решение важнее. Ориентир — Things: светло,
много воздуха, один акцентный синий. Цвета и шрифты — только из `desktop/theme/`,
иконки — только Lucide (`desktop/icons.py`).

## 1. Страница
- **Шапка одна (D86):** крупный заголовок → серая подпись (период · книга) → поиск →
  **одна** синяя кнопка (`PageHeader.primary`) → «⋯» (`PageHeader.more`) для остального.
- Курсива нет. Заголовки — цветом текста; серый — только пояснения, даты, номера.
- Сделанное тише (`P.muted`), ждущее — громче (обычный цвет, янтарная точка).
- Пустая страница объясняет себя и предлагает первое действие (`EmptyState`).

## 2. Страница отчёта
Сверху вниз: шапка (§1) → панель → строка проверки или подсказки → таблица.
- **Панель:** период — капсула «‹ Октябрь 2026 › 📅» (`PeriodField`, D129) · книга (если книг больше одной) ·
  «как подробно» — переключатель из 2–3 положений (`segments`: ОСВ — `Ana hesablar ·
  Subhesablar · Subkonto`, отчётность — `Qısa · Hesablar üzrə · Maddələr üzrə`) · выбор
  страницы («В валюте», «Колонки») · всё редкое — в «⋯» (Excel, сравнение книг, по
  разделам). Своё страница кладёт `add_to_bar`. Кнопки «Сформировать» нет: смена
  периода, книги, вида показывается сразу, F5 читает заново (D127).
- **Строка проверки:** то, что отчёт проверил сам («Дебет и кредит сходятся ✓» зелёной
  галочкой) или как идти глубже («двойной щелчок — карточка»); ошибка — красным.

## 3. Таблица отчёта
Общая для всех: `ReportModel` + `ReportDelegate` + `GroupHeader`
(`desktop/reports_page/table.py`). Новый отчёт строится на ней, а не на своей таблице;
таблица модуля с цифрами (остатки склада) — тоже.
- **Высоты** — константы оттуда же: строка `ROW_HEIGHT` 24, итог `TOTAL_HEIGHT` 28, раздел
  `SECTION_HEIGHT` 34 (воздух сверху); `fit_rows` расставляет их. Списки документов
  (журнал, справочники) — 32–36, это не отчёт.
- **Ширина** — по содержимому, название не шире `NAME_MAX`; свободное место — справа.
- **Числа** — вправо, цифры одной ширины, единицы стоят столбиком; минус — в скобках,
  «)» висит правее столбика. **Ноль — пустая клетка** (не «–»).
- **Сетка (D127)** — бледная (`P.hairline`), включена по умолчанию; «Оформление → Сетка
  в отчётах» выключает. Линия между группами колонок проходит через их подписи, между
  Dt и Kt — только под подписью пары.
- **Группы колонок** («İlkin qalıq / Dövriyyə / Son qalıq») — подпись по центру над парой,
  без своей линии и без фона (полоса под оборотами снята — D127).
- **Зебра** — только по желанию (D103), по умолчанию выключена.
- **Итог** — линия цветом текста над строкой, жирный.

## 4. Строки
| Строка | Вид |
|---|---|
| раздел (класс счетов) | жирный, иконка, воздух сверху |
| счёт верхнего уровня | обычный текст |
| группа счетов (68) | жирный |
| субсчёт, субконто (68.2, контрагент) | `P.secondary`, отступ |
| сумма в валюте под счётом | свой цвет `P.currency`, «USD · valyutada», отступ |
| промежуточный итог (ОПиУ, D128) | жирный, тонкая линия сверху |
| итог | жирный, линия цветом текста сверху |
| ошибка (сальдо не на своей стороне) | красный, пояснение под мышью |

Новый вид строки — сначала сюда, потом в код; цвет — новым токеном палитры, во всех темах.

## 5. Поведение (D106, D104, D116)
- Каждое число ведёт к документу: двойной щелчок / Enter — уровень ниже (отчёт →
  карточка → документ), Esc — назад.
- Правый щелчок по подписям колонок или «⋯ → Колонки…» — выбор колонок, запоминается.
- Ctrl+C — выделенные строки; «⋯ → В Excel» — как на экране (уровни, жирные итоги).
- Выбор вида, детализации, колонок запоминается (`QSettings`).

## 6. Чек-лист нового отчёта
- [ ] Таблица — `ReportModel`/`ReportDelegate`, высоты — `fit_rows`, без своих цветов.
- [ ] Панель как в §2; одна синяя кнопка или ни одной; редкое — в «⋯».
- [ ] Ноль пустой, минус в скобках; группы колонок с подписью, полоса — сама.
- [ ] Строки — по таблице §4; новый вид — сначала в §4.
- [ ] Двойной щелчок ведёт глубже до документа; Excel и Ctrl+C работают.
- [ ] Скриншот (`scripts/screenshots.py`) в светлой и тёмной теме, с сеткой и без.

## Выбор дат (D129)
- Период — одна капсула-поле: ‹ › — соседний период, 📅 — окно периода; ввод «пм», «кв3» как прежде.
- Окно периода: готовые периоды · год (месяцы — `Jan … Dec`, кварталы — «1 кв») · календарь дней.
  Дни: щелчок — начало, второй — конец, будущий диапазон виден под мышью; «Готово» или Enter.
- Календарь дней один на всё (`desktop/day_calendar.py`): неделя с понедельника, без номеров недель
  и красных выходных; выбранное — синее (диапазон — бледная полоса с синими концами), сегодня — обведено,
  чужой месяц — бледный. У поля даты — тот же календарь и «Сегодня».
