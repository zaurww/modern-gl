## Что это
Настольная главная книга для бухгалтера в Азербайджане: проводки Дт/Кт с субконто как в
1С 7.7, несколько компаний (файл на компанию), параллельные книги (общая / МСФО / налог).
**Цель (D30, D111):** сейчас — удобный инструмент для работы владельца; дальше возможны
вся команда и продажа — дорогу к ним не закрывать. Взять простотой — быстро, просто, легко
настраивается. Ядро самодостаточно, модули — по желанию. **Дизайн — главный приоритет**
(Things, craft.do; D86). Рамка — `docs/CONCEPT.md`.

## Как запустить
- Новому человеку — `README.md`.
- `uv run modern-gl` (компании — `*.gl` в «Документы\Modern GL»); `--demo` — демо-компания;
  `--demo-year` — «Xəzər Ofis MMC (demo 2026)», целый год во всех модулях; `--demo-years` —
  она же за 2025 и 2026. Программа открыта — `uv run --no-sync …`.
- Тесты `uv run pytest -q -n auto` (Linux — `QT_QPA_PLATFORM=offscreen`),
  `ruff check`, `ruff format --check`, `pyright` (0 ошибок; strict — D170, `pyproject.toml`); CI —
  ubuntu и windows, покрытие 90 % (D161). Скриншоты: `scripts/screenshots.py <папка> az`.
- Замеры: `uv run python scripts/benchmark.py <папка> --postings 100000` (`--stock`).
- Браузер — D207.
