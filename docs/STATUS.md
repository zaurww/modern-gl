## Что это
Настольная главная книга для бухгалтера в Азербайджане: проводки Дт/Кт с субконто как в
1С 7.7, несколько компаний (файл на компанию), параллельные книги (общая / МСФО / налог).
**Цель (D30, D111):** сейчас — удобный инструмент для работы владельца; дальше возможны
вся команда и продажа — дорогу к ним не закрывать. Взять простотой — быстро, просто, легко
настраивается. Ядро самодостаточно, модули — по желанию. **Дизайн — главный приоритет**
(Things от Cultured Code, craft.do; D86). Рамка — `docs/CONCEPT.md`.

## Как запустить
- `uv run modern-gl` (компании — `*.gl` в «Документы\Modern GL»); `--demo` — демо-компания;
  `--demo-year` — «Xəzər Ofis MMC (demo 2026)», целый год во всех модулях. Программа
  открыта — `uv run --no-sync …`.
- Тесты `uv run pytest -q` (~1075, ~13 мин; в Linux — `QT_QPA_PLATFORM=offscreen` и
  библиотеки как в CI), `uv run ruff check . && uv run ruff format --check .`,
  `uv run pyright` (0 ошибок). Скриншоты: `uv run python scripts/screenshots.py <папка> az`.
- Замеры: `uv run python scripts/benchmark.py <папка> --postings 100000` (`--stock` — склад).

## Что умеет программа
Подробности каждой строки — в решении (`docs/DECISIONS.md`, искать `| D<номер> |`) и в
летописи сессий.

**Ядро — главная книга**
- Документ = 1..N проводок Дт/Кт + до 3 субконто на сторону, деньги — копейки (D1–D3).
  Черновик → проведение; в открытом периоде правка на месте, отмена проведения, удаление
  со следом в журнале действий (D19, D32), в закрытом — сторно (D5). Причина изменения и
  «История изменений» (D96), кто ввёл и провёл (D82).
- Закрытие периода — окно (D95). Слои и книги: общая, МСФО, налог — включаются настройкой
  компании (D7, D63); сравнение книг (D98).
- Ввод: форма документа с клавиатуры как в 1С (D54, D55), быстрая строка Ctrl+L с
  подсказками и «как в прошлый раз» (D94), шаблоны операций с формулами (D23), вставка из
  Excel, импорт многих документов из Excel/CSV, начальные остатки (D39–D40).
- План счетов: шаблоны «classic» (по умолчанию, D21) и «1c77»; код необязателен (D22);
  класс и тип счёта, оборотные/долгосрочные (D14, D17, D35, D89); роли счетов и счёт по
  умолчанию по типу (`application/default_accounts.py`, D93).
- Справочники (субконто): группы, метки, VÖEN, нерезиденты, договоры у контрагентов,
  необязательное субконто, удаление неиспользованного (D20, D28, D36, D59, D60, D64).

## Известные особенности
- ОСВ требует ~1330 px ширины, «Soraqçalar» ~1270 — кандидаты на перекомпоновку.
- `QTest.keyClicks` под Windows падает на не-латинских буквах → в тестах `type_text()`;
  модальные диалоги в тестах подменяются (`no_modal_dialogs`).
- Скриншоты offscreen — экран 800 px, выпадающие списки сдвинуты; поведение списков с
  клавиатуры проверять и в реальном окне (`QT_QPA_PLATFORM=windows`).
- В Git Bash кириллица в аргументах hledger ломается — запускать из PowerShell.
- У пользователя старый `D:\GL AZE\demo.db` (несколько компаний в одном файле) —
  подключается через «Fayldan əlavə et…», программа разложит его по файлам.
