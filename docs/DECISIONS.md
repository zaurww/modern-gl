# Принятые решения

Дополняют и местами заменяют `SPEC.md` / `ARCHITECTURE.md` (v0.1). При расхождении действует этот файл.

| # | Решение | Дата |
|---|---|---|
| D1 | **Проводка = пара Дт/Кт** + сумма (как в 1С 7.7), а не набор строк с признаком стороны. Каждая проводка сбалансирована по построению; анализ счёта по корреспонденции — простой `GROUP BY`. Документ (журнальная запись) содержит 1..N проводок. | 2026-10-19 |
| D2 | **Субконто — часть ядра**, до 3 на счёт. Виды субконто задаются на счёте; при проведении все обязательны и проверяются по виду. | 2026-10-19 |
| D3 | **Деньги — целые копейки** (`INTEGER`), базовая валюта AZN. Больше двух знаков после запятой — ошибка, без молчаливого округления. Валюта и курсы — позже, отдельной миграцией. | 2026-10-19 |
| D4 | **Один файл SQLite на все компании**, изоляция через `company_id` и составные внешние ключи `(company_id, id)`. | 2026-10-19 |
| D5 | **Исправление проведённого — красное сторно**: новый документ с теми же проводками и отрицательными суммами, `reversal_of` ссылается на оригинал. Оригинал не меняется (запрещено триггерами). Сторно сторно и повторное сторно запрещены. | 2026-10-19 |
| D6 | **Развёрнутое сальдо**: у активно-пассивного счёта с субконто сальдо в ОСВ сворачивается по 1-му субконто, а не по счёту целиком (дебиторка и кредиторка не взаимозачитываются). Строки групп = сумма колонок подчинённых. | 2026-10-19 |
| D7 | **Слой ≠ книга**: документ лежит ровно в одном слое (`common`, `ifrs_adj`, `tax_adj`), книга = список слоёв. Таблица `books` появится, когда понадобится настройка; пока книги — константы в `reporting`. | 2026-10-19 |
| D8 | **Без выгрузки из 1С 7.7.** Эталон корректности — примеры, посчитанные вручную (`tests/conftest.py`). План счетов загружается из CSV; `examples/demo_chart.csv` — демо, не реальный план. | 2026-10-19 |
| D9 | **Чистый `sqlite3` + SQL-миграции по `PRAGMA user_version`** вместо SQLAlchemy/Alembic на этапе прототипа. Пересмотреть при переходе на PostgreSQL. | 2026-10-19 |
| D11 | **План счетов по умолчанию — шаблон «1c77»**: двухзначные коды как в 1С 7.7 (бухгалтерия ред. 4.x, план счетов 2000 г.), субсчета вида `60.1`; счёт с субсчетами — группа, проводки только на субсчета. 92 счёта, 11 видов субконто. Забалансовые счета (001–011), количественный и валютный учёт пока не поддерживаются. Файлы: `src/modern_gl/infrastructure/templates/`. | 2026-10-19 |
| D12 | **Интерфейс на азербайджанском и русском**, по умолчанию азербайджанский; переключение в меню компании. Ключи перевода — русские строки в коде. План счетов при создании компании берётся на текущем языке (названия потом хранятся в базе). | 2026-10-19 |
| D13 | **Нули в отчётах не показываются** (пустая ячейка, как в 1С), кроме строк «Итого» — там 0.00. | 2026-10-19 |
| D14 | **Класс счёта (уровень 1 классификации для отчётности)**: asset / liability / equity / revenue / expense + признак контрсчёта; NULL = не задан. Новый счёт наследует класс родителя, иначе A→asset, P→liability. Смена класса группы переносится на субсчета, которые имели тот же класс. Строки отчётов (уровень 2) — позже, отдельной таблицей сопоставлений на каждую форму. | 2026-10-19 |
| D15 | **Редактирование плана счетов**: добавить / изменить / сменить код / скрыть. Удаления нет — скрытый счёт не предлагается при вводе, но остаётся в истории и отчётах. Счёт с проводками нельзя превратить в группу и нельзя менять его субконто. Первый субсчёт у счёта без проводок делает его группой. | 2026-10-19 |
| D16 | **Банки — через субконто «Банковские счета» на 51** (по умолчанию). Кто хочет видеть банки строками ОСВ — галочка «Развернуть по субконто» (одно и то же хранение, два вида). Субсчета 51.1/51.2 тоже возможны через редактирование плана. | 2026-10-19 |
| D17 | **Вид счёта (A / P / AP) убран.** Нормальная сторона сальдо выводится из класса (актив, расход — дебет; обязательство, капитал, доход — кредит; контрсчёт — наоборот). Вместо «AP» — флаг `two_sided` (сальдо бывает с обеих сторон, развёрнуто по субконто, не проверяется). ОСВ подсвечивает красным сальдо не на своей стороне. Колонка `kind` в CSV по-прежнему понимается при импорте. | 2026-10-19 |
| D10 | Номер документа — сквозной по компании, присваивается при создании (порядок ввода, не дата). | 2026-10-19 |

## Ещё не решено
- Сверить шаблон «1c77» с привычным пользователю (лишние/недостающие счета и субконто).
- Нужна ли позже сопоставка с национальным планом счетов АР для обязательной отчётности.
- Валюты: переоценка, источник курсов.
- Закрытие месяца (закрытие затратных счетов, финрезультат), типовые операции.
- Развёрнутое сальдо по 2-му/3-му субконто (сейчас только по 1-му).
- Согласованные примеры по слоям МСФО/налог с заменой (а не дополнением) общих проводок.
